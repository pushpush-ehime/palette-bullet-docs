# このサイトの使い方

## 読む順番

1. [仕様・設計](/spec/)で機能の仕様を確認します。
2. [タスク一覧](/tasks/)で自分の作業を確認します。

## 管理場所
### Webで仕様、Notionでタスク

| 場所 | 管理する内容 |
|---|---|
| Web＋GitHub | 正式な仕様・設計・タスク説明 |
| Notion | 担当者・状態・優先度・期限 |

## 仕様状態・・・新旧仕様が混在している可能性があるので、確認してください。

| 状態 | 意味 |
|---|---|
| 確定 | 実装と確認の基準にする |
| 仮仕様 | 実装できるが、変更の可能性がある |
| 未決 | 決定するまで実装しない |
| 対象外 | このページやタスクでは扱わない |
| 廃止 | 使用しない |

## タスクID

`PB-TASK-0001`の形式を使います。

- `PB`：Palette Bullet
- `TASK`：タスク
- `0001`：通し番号

タスクを追加するたびに通し番号を1増やしてください。
