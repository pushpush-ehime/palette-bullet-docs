# このサイトの使い方

## サイトの機能
### 以下の二つのページの📚「追加」と👀「確認」が可能です。

1. [仕様・設計](/spec/)・・・仕様の一覧が並んでいます。
2. [タスク説明](/tasks/)・・・タスクの一覧が並んでいます。

## 📚「追加」・・・仕様とタスクを作ってください。
1. [仕様・設計](/guide/new-page)から仕様の追加ができます。
2. [タスク説明](/guide/new-page)からタスクの追加ができます。

## 👀「確認」・・・タスクを行う前に見てください。
1. [仕様・設計](/spec/)から仕様の確認ができます。
2. [タスク説明](/tasks/)からタスクの確認ができます。

## 未確定事項を追加する

[未確定事項一覧](/open-questions)には、サイト内の全ページから未確定事項が自動で集約されます。

次のどちらかの方法で追加できます。

### 箇条書きの末尾にマーカーを付ける

任意の場所にある箇条書きの末尾へ`（未確定）`と記載します。

```md
- スキル（未確定）
```

### 未決事項セクションに記載する

`## 未決事項`見出しの下へ箇条書きで記載します。この方法では、各項目に`（未確定）`を付ける必要はありません。

```md
## 未決事項

- スキルの発動条件
- スキルのクールタイム
```

Markdownの変更がサイトへ反映されると、一覧も自動で更新されます。解決した項目は、末尾の`（未確定）`を外すか、`## 未決事項`から箇条書きを削除・移動してください。
