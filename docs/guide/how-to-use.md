# このサイトの使い方

## 読む順番

1. [ゲーム概要](/game-overview)で全体を知ります。
2. [仕様・設計](/spec/)で機能の仕様を確認します。
3. [タスク一覧](/tasks/)で自分の作業を確認します。

## 管理場所

| 場所 | 管理する内容 |
|---|---|
| Web | 正式な仕様・設計・タスク説明 |
| Notion | 担当者・状態・優先度・期限 |
| GitHub | 実装・変更履歴・Pull Request |

## 仕様状態

| 状態 | 意味 |
|---|---|
| 確定 | 実装と確認の基準にする |
| 仮仕様 | 実装できるが、変更の可能性がある |
| 未決 | 決定するまで実装しない |
| 対象外 | このページやタスクでは扱わない |
| 廃止 | 使用しない |

## 仕様と実装が違う場合

1. 実装だけを変更しません。
2. 関連するNotionタスクで差分を報告します。
3. 仕様を変更する場合は、このサイトも更新します。
4. Pull Requestに仕様ページを記載します。

## タスクID

`PB-TASK-0001`の形式を使います。

- `PB`：Palette Bullet
- `TASK`：タスク
- `0001`：通し番号
