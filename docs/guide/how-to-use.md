# このサイトの使い方

## サイトの機能
### 以下の二つのページの📚「追加」と👀「確認」が可能です。

1. [仕様・設計](/spec/)・・・仕様の一覧が並んでいます。
2. [タスク説明](/tasks/)・・・タスクの一覧が並んでいます。

## 📚「追加」・・・仕様とタスクを作ってください。
1. [仕様・設計](/guide/new-page)から仕様の追加ができます。
2. [タスク説明](/guide/new-page)からタスクの追加ができます。

## 👀「確認」・・・タスクを行う前に見てください。
1. [仕様・設計](/spec/)から仕様の確認ができます。
2. [タスク説明](/tasks/)からタスクの確認ができます。
