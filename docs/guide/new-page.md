# ページを追加する

## 新しいカテゴリを作る

### 仕様カテゴリ

1. 下のテンプレートをコピーします。
2. 「仕様カテゴリを作成」を押します。
3. 新しいフォルダ名を付けます。
4. `index.md`を作成します。
