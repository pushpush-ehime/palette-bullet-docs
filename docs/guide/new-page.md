# ページを追加する

仕様ページ、タスクページ、カテゴリを追加する方法を説明します。

## 追加方法を選ぶ

作りたい内容に合わせて、次の方法を使用します。

- 新しい分類が必要：新しいカテゴリを作る
- 既存カテゴリへ仕様を追加：カテゴリの「＋ このカテゴリにページを追加」を使う
- 仕様を実装するタスク：仕様ページの「＋ タスクを生成」を使う
- 仕様に直接関係しない管理作業：タスクカテゴリから直接作る

仕様に関係するタスクは、仕様ページの「＋ タスクを生成」から作る方法を推奨します。

---

## 新しいカテゴリを作る

仕様またはタスクに、新しい分類が必要な場合に使用します。

### 仕様カテゴリ

1. [仕様カテゴリ作成フォーム](/guide/create-category?type=spec)を開きます。
2. カテゴリ名を入力します。
3. フォルダ名を英小文字・数字・ハイフンで入力します。
4. サイドバーでの表示順を入力します。
5. 「GitHubでカテゴリを作成」を押します。
6. 自動的にコピーされた内容をGitHubの編集欄へ貼り付けます。
7. 内容を確認してPull Requestを作成します。

### タスクカテゴリ

1. [タスクカテゴリ作成フォーム](/guide/create-category?type=task)を開きます。
2. カテゴリ名を入力します。
3. フォルダ名を英小文字・数字・ハイフンで入力します。
4. サイドバーでの表示順を入力します。
5. 「GitHubでカテゴリを作成」を押します。
6. 自動的にコピーされた内容をGitHubの編集欄へ貼り付けます。
7. 内容を確認してPull Requestを作成します。

同じフォルダ名のカテゴリがすでに存在する場合は作成できません。

---

## 既存カテゴリへ追加する

既存カテゴリへ、新しい仕様ページを追加する方法です。

1. [仕様・設計一覧](/spec/)を開きます。
2. 追加先のカテゴリを開きます。
3. サイドバーのカテゴリ末尾にある「＋ このカテゴリにページを追加」を押します。
4. ページタイトルを入力します。
5. ファイル名を英小文字・数字・ハイフンで入力します。
6. 仕様の状態を選択します。
7. 「本文をコピーしてGitHubを開く」を押します。
8. 自動的にコピーされた内容をGitHubの編集欄へ貼り付けます。
9. 仕様内容を記入してPull Requestを作成します。

ファイル名に`.md`を入力する必要はありません。

例：
jump-action

同じカテゴリに同じファイル名が存在する場合は作成できません。

---

## 仕様からタスクを作る

仕様を実装するタスクは、この方法で作成します。

1. タスクにしたい仕様ページを開きます。
2. ページ上部の「＋ タスクを生成」を押します。
3. GitHubの新規ファイル作成画面が開きます。
4. 自動入力された内容を確認します。
5. 未記入部分を完成させます。
6. Pull Requestを作成します。

次の内容は自動的に設定されます。

* タスクID
* ファイル名
* タスクカテゴリ
* 関連する仕様
* 仕様の目的
* 実装時の注意点
* タスクページの標準見出し

Pull Requestを作る前に、少なくとも次の項目を記入してください。

* タスクの目的
* 実施内容
* 完了条件
* 確認手順

::: warning
仕様に関係するタスクは、タスクカテゴリから直接作らず、仕様ページの「＋ タスクを生成」から作ってください。
