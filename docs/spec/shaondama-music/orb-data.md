# 玉のデータ

## ページ概要

- 対象担当：プログラム班・企画班（RGBダメージ値はプランナー成果物）
- 出典：統合仕様書v3.2 §4.2.3・§5.2
- 関連ページ：[MIDI駆動生成](/spec/shaondama-music/midi-driven-spawning)、[万能シャオンダマ](/spec/shaondama-music/wildcard-orb)

## 目的

シャオンダマ1個が持つデータ属性を定義し、生成・照合・ダメージ計算の各システムが参照する共通の土台を作ります。

## プレイヤーから見た挙動

- 玉の色を見れば、どの音程の玉かが分かる
- 玉を選択したとき・玉が破裂したときに、それぞれ固有の音が鳴る

## 詳細仕様

各玉は以下のデータを持ちます。

| 属性 | 内容 |
|---|---|
| 音程（ピッチクラス） | オクターブを区別しない音程。コード照合の単位 |
| 色 | キーからの度数に対応した7色のいずれか（対応表は[MIDI駆動生成](/spec/shaondama-music/midi-driven-spawning)参照） |
| RGBダメージ値 | 浄化ダメージの元となるRGB値。7色分の具体値は未解決（§5.2 プランナー成果物） |
| 選択音 | ドローモードで選択したときに鳴る音 |
| 破裂音 | 破裂したときに鳴る音 |

## 状態別の挙動

なし（データ定義のみ。状態ごとの挙動は[浮遊・挙動](/spec/shaondama-music/floating-behavior)参照）

## 他システムとの接続

- 生成時の属性付与：[MIDI駆動生成](/spec/shaondama-music/midi-driven-spawning)
- 音程を使ったコード分類・照合：BGMカテゴリ（作成予定）
- RGBダメージ値を使った浄化ダメージ計算：Combatカテゴリ（作成予定）

## 例外・禁止事項

- 旧仕様の3色前提のRGBダメージ値 (510, 255, 510) を使用しない（7色前提で再設計する）
- RGBダメージ値をコードにハードコードしない（ScriptableObject等でプランナーが調整可能にする）

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| 7色分のRGBダメージ値 | 未定 | 🔴未解決（実装前に企画確認必須） |

## 未決事項

- 7色分のRGBダメージ値と敵最大浄化値の対応（§5.2 プランナー成果物。実装前に企画確認必須）
