# 浮遊・挙動

## ページ概要

- 対象担当：プログラム班・デザイン班
- 出典：統合仕様書v3.2 §4.2.2
- 関連ページ：[シャオンダマ](/spec/shaondama-music/)、[シャオンダマ生成](/spec/bgm/bgm-make-syaonndama)、[ラジクジラ｜シャオンダマ生成](/spec/radiowhale/shaondama-spawning)、[Playerアクション｜チャージ](/spec/player/player-action-charge)

## 目的

本ページでは、**ラジクジラから世界内へ出現した後のシャオンダマ**について、生成後の浮遊・Lifetime・消滅を定義します。

ラジクジラはシャオンダマを世界内へ出現させるところまでを担当し、出現後はシャオンダマ側へ制御と責務が移ります。

本ページでは、シャオンダマの生成対象・生成タイミング・生成個数や、ラジクジラから世界内へ出現するまでの処理、PlayerによるChargeなどは定義しません。

## プレイヤーから見た挙動

- シャオンダマは、世界内へ出現した後、独立したオブジェクトとして空中を漂う
- 浮遊中の具体的な移動範囲・速度・配置方法などは未決とする
- シャオンダマにはLifetimeが存在する
- Lifetimeは**数十秒程度**を想定する方向とする
- Lifetime終了時は、**割れて消える方向**とする
- Lifetimeの正式な秒数は未決とする

## 詳細仕様

### 制御開始

シャオンダマの生成に関する責務は、以下のように分離します。

```text
BGM / MusicChart
「何を・いつ・何個生成するか」
        ↓
生成要求
        ↓
ラジクジラ
「世界内へ出現させる」
        ↓
シャオンダマ側へ制御移譲
        ↓
本ページ
「生成後の浮遊・Lifetime・消滅」
```

ラジクジラから世界内へ出現し、シャオンダマ側へ制御が移譲された後の挙動を本ページの対象とします。

生成対象・生成タイミング・生成個数については、BGM側の仕様を正本とします。

ラジクジラの背中から世界内へ出現するまでの処理については、ラジクジラ側の仕様を正本とします。

### 浮遊

生成後のシャオンダマは、世界内で空中を漂うオブジェクトとして扱います。

ただし、現在の詳細な浮遊アルゴリズムは未決です。

以下については、本ページの現段階では具体値・具体方式を確定しません。

* 浮遊範囲
* 配置方法
* 移動速度
* 移動方向の決定方法
* 他のシャオンダマとの位置関係
* Playerや敵との位置関係を利用した配置・移動ルール

特に、**敵の周囲を基準として浮遊させる仕様は採用しません**。

### Lifetime

シャオンダマにはLifetimeを設定します。

* Lifetimeが存在する
* 数十秒程度を想定する方向とする
* 正式な秒数は未決とする
* Lifetime終了時は、シャオンダマが割れて消える方向とする

Lifetimeの具体値は、今後の調整によって決定します。

### 戦闘終了時

戦闘終了時に世界内へ残っているシャオンダマについては、生成後オブジェクト側で処理する領域とします。

ただし、戦闘終了時に、

* 即座に消滅させるか
* 演出を伴って消滅させるか
* その他の処理を行うか

といった**具体的な後処理は未決**です。

## 状態別の挙動

### 生成後

ラジクジラから世界内へ出現し、シャオンダマ側へ制御が移譲された後は、本ページで定義する生成後オブジェクトとして扱います。

生成後はラジクジラ自身の追従・浮遊処理から独立して存在します。

### 浮遊中

Lifetimeが終了するまで、シャオンダマは世界内に存在し、空中を漂います。

詳細な浮遊アルゴリズムは未決です。

### Lifetime終了時

Lifetimeが終了したシャオンダマは、**割れて消える方向**とします。

具体的な消滅演出の詳細は未決です。

### 戦闘終了時

戦闘終了時に残存しているシャオンダマの具体的な処理は未決です。

## 他システムとの接続

### BGM / MusicChart

シャオンダマについて、

* 何を生成するか
* いつ生成するか
* 何個生成するか

といった生成ロジックは、[シャオンダマ生成](/spec/bgm/bgm-make-syaonndama)を正本とします。

MusicChart / NoteEventの構造については、BGMカテゴリ側を正本とします。

本ページではこれらの生成ロジックを再定義しません。

### ラジクジラ

ラジクジラは、生成要求を受け取ったシャオンダマを世界内へ出現させるところまでを担当します。

詳細は[ラジクジラ｜シャオンダマ生成](/spec/radiowhale/shaondama-spawning)を正本とします。

本ページでは、**ラジクジラからシャオンダマ側へ制御が移譲された後**を扱います。

ラジクジラ自身のPlayer追従・浮遊については、本ページでは扱いません。

### Charge

生成済みシャオンダマをPlayerが選択した後のCharge処理は、[Playerアクション｜チャージ](/spec/player/player-action-charge)を正本とします。

本ページではChargeの開始条件・処理・終了条件などを再定義しません。

また、旧仕様に存在した**選択されたシャオンダマ自体が敵へ飛んでいく挙動は採用しません**。

### AttackEvent

AttackEventの成立・発火・処理についてはBGM側のAttackEvent仕様を正本とし、本ページでは定義しません。

## 責務外

本ページでは、以下の内容を詳細定義しません。

* MusicChartの構造
* NoteEventの選択ロジック
* 生成対象Track
* 生成タイミング
* 生成個数
* `InitialTargetCount`
* `MinimumLeadTime`
* ラジクジラ側の生成位置
* ラジクジラ側の生成演出
* ラジクジラ自身のPlayer追従・浮遊
* Charge
* AttackEvent
* Player State
* 万能シャオンダマの生成仕様

また、現在の仕様には**Draw Modeを前提とした浮遊状態を設けません**。

そのため、

* Draw Mode中だけ浮遊を変化させる
* Draw Mode中にscaled timeによって浮遊をスローにする

といった旧仕様は、本ページでは扱いません。

## パラメータ

| パラメータ    | 値        | 状態      |
| -------- | -------- | ------- |
| Lifetime | 数十秒程度を想定 | 🟡正式値未決 |
| 浮遊範囲     | 未定       | 未決      |
| 配置方法     | 未定       | 未決      |
| 浮遊速度     | 未定       | 未決      |

## 未決事項

* Lifetimeの正式な秒数
* Lifetime終了時の具体的な消滅演出
* 戦闘終了時に残っているシャオンダマの具体的な処理
* 生成後の詳細な浮遊アルゴリズム
* 浮遊範囲
* 配置方法
* 浮遊速度

これらは現段階では推測で確定せず、今後の仕様決定・調整によって定義します。
