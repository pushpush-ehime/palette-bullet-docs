# 浮遊・挙動

## ページ概要

- 対象担当：プログラム班・デザイン班
- 出典：統合仕様書v3.2 §4.2.2（本文の一部はカテゴリ概要ページから移設）
- 関連ページ：[MIDI駆動生成](/spec/shaondama-music/midi-driven-spawning)、[ドローシステム](/spec/draw-system/)、[シャオンダマ選択との接続](/spec/player/shaondama-selection-connection)

## 目的

シャオンダマは、シャボン玉のように空中を漂う表現をコンセプトとします。

また、シャオンダマを常にプレイヤーの画面内に表示し、プレイヤーが旋律を奏でやすい状態を維持します。

## プレイヤーから見た挙動

- 玉はシャボン玉のように敵の周囲をゆっくり漂う
- 玉同士は近づきすぎず、適度な間隔を保つ
- プレイヤーから離れすぎた玉は割れて消える

## 詳細仕様

- 空中を漂う。玉同士は**斥力で反発**し、密集しない（斥力の強さは仮値未定）
- プレイヤーから一定距離以上離れると割れて消える（距離リーシュ）
- 選択（予約）中および待機コード化した玉の距離超過の扱いは、待機コード仕様（Combatカテゴリ・作成予定）で定義する
- 玉の漂い・飛翔はscaled time（ドローモードのスローの影響を受ける）

## 状態別の挙動

### 通常時

- シャオンダマは、敵の周囲で一定の距離を保ちながら空中に浮遊する
- 敵の周囲にいるシャオンダマが少なくなった場合、敵から離れた位置にあるシャオンダマが、敵の周囲へゆっくりと集まる
- 敵の周囲に集まったシャオンダマは、その位置を基準として緩やかに上下運動する
- 上下運動によって、シャボン玉が空中を漂っているような見た目を表現する

### ドローモード時

- プレイヤーカメラから見て、シャオンダマ同士の表示面積が一定以上重なっている場合、奥側にあるシャオンダマの色を薄暗くする
  - 判定基準：奥側のシャオンダマの表示面積の5%以上が隠れた場合
- プレイヤーがタッチして選択したシャオンダマは、色のトーンを上げて強調表示する

### 攻撃発動時

- プレイヤーが選択したシャオンダマは、敵に向かって移動する
- 敵に到達したシャオンダマは、シャボン玉のようにはじける
- 発射トリガー・ターゲティング・飛翔の詳細はCombatカテゴリ（作成予定）で定義する

- 生成：[MIDI駆動生成](/spec/shaondama-music/midi-driven-spawning)

## 例外・禁止事項

- 待機コード化した玉は漂わずその場に固定される（詳細は待機コード仕様で定義。本ページの浮遊仕様は適用外）

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| 距離リーシュ（割れて消える距離） | 20m | 🟡仮 |
| 斥力の強さ | 未定 | 🟡仮値未定 |
| 重なり判定のしきい値 | 表示面積の5% | 🟡仮 |
| 上下運動の振幅・周期 | 未定 | 未決 |

## 未決事項

- 斥力の強さの仮値
- 上下運動の振幅・周期
- 「敵の周囲へ集まる」挙動の速度・距離しきい値
