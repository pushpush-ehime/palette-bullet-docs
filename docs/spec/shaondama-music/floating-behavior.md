# 浮遊・挙動

## ページ概要

- 対象担当：プログラム班・デザイン班
- 出典：統合仕様書v3.2 §4.2.2
- 関連ページ：MIDI駆動生成（作成中）、[ドローシステム](/spec/draw-system/)、[シャオンダマ選択との接続](/spec/player/shaondama-selection-connection)

## 目的

シャオンダマは、シャボン玉のように空中を漂う表現をコンセプトとします。

また、シャオンダマを常にプレイヤーの画面内に表示し、プレイヤーが旋律を奏でやすい状態を維持します。

## プレイヤーから見た挙動

- 玉はシャボン玉のように敵の周囲をゆっくり漂う
- 玉同士は近づきすぎず、適度な間隔を保つ
- プレイヤーから離れすぎた玉は割れて消える

## 詳細仕様

- 空中を漂う。玉同士は**斥力で反発**し、密集しない
- 漂いの移動は、一定間隔で方向を抽選するのではなく、滑らかに変化するノイズ（擬似的な風）で表現する想定
- プレイヤーから一定距離以上離れると割れて消える（距離リーシュ）
- 選択（予約）中および待機コード化した玉の距離超過の扱いは、待機コード仕様（Combatカテゴリ・作成予定）で定義する
- 玉の漂い・飛翔はscaled time（ドローモードのスローの影響を受ける）

## 状態別の挙動

### 通常時

- シャオンダマは、敵の周囲の範囲内を、**空気の流れに流されるように滑らかに移動し続ける**（定位置に留まらない）
- 移動方向は急に切り替わらず、緩やかなカーブを描いて変化する
- 移動の速度は、シャボン玉が風に流されるような緩やかさとする
- 敵の周囲にいるシャオンダマが少なくなった場合、敵から離れた位置にあるシャオンダマが、敵の周囲へゆっくりと集まる
- この移動によって、シャボン玉が空中を漂っているような見た目を表現する

### ドローモード時

- プレイヤーカメラから見て、シャオンダマ同士の表示面積が一定以上重なっている場合、奥側にあるシャオンダマの色を薄暗くする
  - 判定基準：奥側のシャオンダマの表示面積の5%以上が隠れた場合
- プレイヤーがタッチして選択したシャオンダマは、色のトーンを上げて強調表示する
- 漂いの移動はscaled timeのため、ドローモード中は0.2倍速まで遅くなり、なぞり選択の狙いやすさを保つ

### 攻撃発動時

- プレイヤーが選択したシャオンダマは、敵に向かって移動する
- 敵に到達したシャオンダマは、シャボン玉のようにはじける
- 発射トリガー・ターゲティング・飛翔の詳細はCombatカテゴリ（作成予定）で定義する

## 他システムとの接続

- 生成：MIDI駆動生成ページ（作成中）
- なぞり・選択操作：[ドローシステム](/spec/draw-system/)、[シャオンダマ選択との接続](/spec/player/shaondama-selection-connection)
- 発射・飛翔・ダメージ：Combatカテゴリ（作成予定）

## 例外・禁止事項

- 待機コード化した玉は漂わず、その場に固定される（詳細は待機コード仕様で定義。本ページの浮遊仕様は適用外）

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| 距離リーシュ（割れて消える距離） | 20m | 🟡仮 |
| 斥力の強さ | 未定 | 🟡仮値未定 |
| 重なり判定のしきい値 | 表示面積の5% | 🟡仮 |
| 漂う速度 | 未定 | 未決 |
| 風向きが変化する速さ（経路の滑らかさ） | 未定 | 未決 |
| 移動範囲 | 未定 | 未決 |

## 未決事項

- 斥力の強さの仮値
- 漂う速度・風向きが変化する速さ（なぞり選択の狙いやすさとのバランスをプレイテストで確認）
- 移動範囲（散布半径4mと共通にするか、別に定義するか）
- 「敵の周囲へ集まる」挙動の速度・距離しきい値
- 敵がいない場面（敵全滅後・戦闘外）での浮遊位置（MIDI駆動生成の未決事項と共通）
