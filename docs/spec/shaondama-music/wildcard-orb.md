# 万能シャオンダマ

## ページ概要

- 対象担当：プログラム班・企画班
- 出典：統合仕様書v3.2 §4.2.4
- 関連ページ：[MIDI駆動生成](/spec/shaondama-music/midi-driven-spawning)、[玉のデータ](/spec/shaondama-music/orb-data)

## 目的

コード構成の自由度を上げる救済要素として、どの音程にもなれるワイルドカードの玉を定義します。

## プレイヤーから見た挙動

- ラジクジラから時々、虹色のシャオンダマが生まれる
- スキル（Q）でも虹色の玉を生成できる
- 虹色の玉はコードのどの構成音の代わりにも使える

## 詳細仕様

- ラジクジラが**一定間隔**で生成する。**スキル（Q）**でも生成する
- 固有の色・音程を持たない（見た目は虹色）
- 使用（発音）時はBGMで使われている音がそのまま鳴り、BGMとの整合を保つ
- コード照合上は**ワイルドカード**として機能する（例：C＋万能 → C5として成立しうる）
- ワイルドカードの解決規則：BGMが鳴らしたコードID起点で、待機構成の不足音に万能玉を割り当てて一致できれば一致とみなす（照合ルールの詳細はBGMカテゴリ・作成予定で定義）

## 状態別の挙動

なし（浮遊・選択・攻撃時の挙動は通常の玉と同じ。[浮遊・挙動](/spec/shaondama-music/floating-behavior)参照）

## 他システムとの接続

- 生成元：ラジクジラ、およびプレイヤーのスキル（Playerカテゴリ・スキル仕様は未定）
- コード照合でのワイルドカード解決：BGMカテゴリ（作成予定）

## 例外・禁止事項

- 万能玉自体に固有のRGBダメージ値・固有音を持たせない（発音は常にBGM由来）

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| 生成間隔（ラジクジラ） | 8秒 | 🟡仮 |
| スキル生成の個数・クールタイム | 未定 | 🔴未解決 |

## 未決事項

- 万能玉の生成間隔の正式値・スキルの正式仕様（実装前に企画確認必須）
- スキル（Q）で生成する個数・クールタイム
