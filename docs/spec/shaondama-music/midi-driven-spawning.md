# MIDI駆動生成（旧ページ）

## 目的

本ページは、旧「MIDI駆動生成」仕様の移行案内です。

シャオンダマ生成に関する仕様は責務ごとに分離されています。
現在の詳細仕様は、本ページではなく以下の各正本ページを参照してください。

## 現在の正本

| 内容 | 正本 |
|---|---|
| 何を・いつ・何個生成するか | [BGM側のシャオンダマ生成仕様](../bgm/bgm-make-syaonndama.md) |
| 生成要求を受け、ラジクジラの背中側から世界内へ出現させる処理 | [ラジクジラ｜シャオンダマ生成](../radiowhale/shaondama-spawning.md) |
| 出現後の浮遊・Lifetime・消滅等 | [シャオンダマ｜浮遊・挙動](./floating-behavior.md) |

通常シャオンダマが**ラジクジラの背中側から世界内へ出現する**仕様は現在も有効ですが、その詳細は「ラジクジラ｜シャオンダマ生成」を正本とします。

## 旧仕様の扱い

本ページで以前定義していた以下の内容は、現在の仕様には引き継ぎません。

- `n = 4小節`固定の生成
- 敵周囲への散布
- Draw Modeを前提とした生成・配置
- 旧BGMデータ構造を前提とした接続
- ラジクジラ自身が生成対象・生成タイミング・生成個数を判断する構造

本ページでは、生成ロジック、ラジクジラによる出現処理、生成後のシャオンダマ挙動を再定義しません。
