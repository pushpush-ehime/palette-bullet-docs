# 追跡移動

## ページ概要

- 対象担当：プログラム班・企画班
- 関連ページ：[敵](/spec/enemy/)、[戦闘](/spec/combat/)、[ステージ](/spec/stage/)

## 目的

敵がプレイヤーへ近づくための移動ルールを定義します。

## プレイヤーから見た挙動

- 敵は常にプレイヤーのいる方向へ向かって移動してくる
- 距離を取って逃げても追いかけてくる
- 一定距離まで近づかれると攻撃（邪音玉の発射）が始まる

## 詳細仕様

- **追跡対象**：プレイヤー1人のみを対象とする（プロトタイプはシングルプレイ）
- **追跡開始**：戦闘状態（`Combat`）の間は常にプレイヤーを追跡する（索敵範囲・見失いの概念は設けない）
- **移動**：プレイヤーの現在位置へ向かって移動する。移動速度は未決
- **攻撃開始距離との関係**：プレイヤーとの距離が攻撃開始距離以下になったときに移動を止めるか、移動しながら攻撃するかは未決
- **経路**：障害物や他の敵を回避するか（経路探索を使うか直線移動か）は未決

## 状態別の挙動

- 戦闘状態（`Combat`）中：常にプレイヤーを追跡する
- 非戦闘状態（`NonCombat`）中：敵の存在・挙動は未決（戦闘開始条件と合わせてCombat System側で定義予定）
- 攻撃中：移動を継続するか停止するかは未決
- 浄化済み：移動を停止する

## 他システムとの接続

- **戦闘状態**：追跡の開始・終了は戦闘状態（`Combat`／`NonCombat`）に従う（[戦闘](/spec/combat/)）
- **攻撃**：攻撃開始距離の判定は攻撃側の仕様と共有する（「邪音玉」ページで定義。作成予定）
- **ステージ**：移動可能範囲・障害物の配置はステージ仕様に従う（[ステージ](/spec/stage/)）

## 例外・禁止事項

- 敵がステージの移動可能範囲の外へ出ないこと
- パラメータ類はハードコードせず、Inspectorで調整可能にする（`[SerializeField]` または ScriptableObject）

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| 移動速度 | 未決 | 🔴 |
| 旋回速度（方向転換の速さ） | 未決 | 🔴 |
| 攻撃開始距離 | 未決（攻撃側の仕様と共有） | 🔴 |

## 未決事項

- 移動速度・旋回速度の数値
- 移動方式（経路探索を使うか、プレイヤーへの直線移動か。障害物回避の要否）
- 攻撃開始距離に到達したときの挙動（停止するか、移動しながら攻撃するか、距離を維持するか）
- 攻撃中に移動を継続するか
- 複数の敵が同時にいる場合の挙動（重なり回避・間隔の確保をするか）
- 非戦闘状態での敵の存在・挙動（戦闘開始条件との関係）
