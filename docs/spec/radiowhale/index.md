# ラジクジラ

## 目的

本ページでは、Palette Bulletにおける**ラジクジラそのものの基本仕様と、関連システムとの責務境界**を定義します。

ラジクジラカテゴリ全体の入口として、

- ラジクジラとはGameplay上どのような存在か
- Gameplay上で何を担当するか
- 何を担当しないか
- 詳細仕様をどのページで管理するか

を整理します。

行動パターンと設定解放、追従処理、シャオンダマの生成演出、Gameplay上の表示制御、Animation・VFX・Sound、世界観などの詳細は、それぞれの専用ページを正本とします。

## ラジクジラとは

ラジクジラは、**Playerの相棒として行動する存在**です。

ラジクジラは行動パターンによって自動で動きます。最初のチュートリアルでは、自律的に浮遊しながらPlayer周辺を追従するパターンを使用します。この追従も行動パターンの一つです。

Playerによるパターンの組み替え・継続小節数の設定は、ストーリークリア後に解放します。事前に動作を設定することと、演奏中にラジクジラを直接操縦することは区別します。追従以外の具体的な動作は未決です。

Gameplay上ではPlayerとは独立した存在として扱い、PlayerのStateには含めません。

初期行動・設定解放・曲との同期・担当範囲は[行動パターンと設定解放](./behavior-patterns.md)、追従パターンの浮遊・位置補正は[追従・浮遊](./follow-and-floating.md)を正本とします。

## Gameplay上の役割

ラジクジラのGameplay上の主要な役割は、**通常シャオンダマを世界内へ出現させること**です。

シャオンダマの生成対象・生成タイミング・生成個数をラジクジラ自身が判断することはありません。

生成に関する責務は、次のように分離します。

```text
BGM / MusicChart
「何を・いつ・何個生成するか」を決定
        ↓
Spawn System
「生成要求」を渡す
        ↓
ラジクジラ
「受け取った生成要求を世界内の出現表現へ変換」
        ↓
シャオンダマ
「出現後の存在・浮遊・Lifetime・選択等を担当」
```

つまり、

**BGM／MusicChartが「何を・いつ生成するか」を決め、ラジクジラは「それを世界内でどう出現させるか」を担当し、出現後はシャオンダマ側が責任を持つ**

という関係です。

ラジクジラが生成する対象は**通常シャオンダマ**です。

万能シャオンダマはラジクジラの生成対象には含めません。

## 基本仕様

| 項目         | 仕様                  |
| ---------- | ------------------- |
| Playerとの関係 | Playerの相棒           |
| 移動         | 行動パターンで自動実行する。初期はPlayer追従 |
| 行動設定       | ストーリークリア後にPlayerへ解放する |
| 直接操作       | 演奏中の直接操縦を必須にしない。事前設定で行動を組む |
| 戦闘中の存在     | 戦闘中は基本的に存在する        |
| 敵からの攻撃     | 攻撃対象にならない           |
| HP         | 持たない                |
| Damage     | 持たない                |
| Dead       | 持たない                |
| 行動不能状態     | 持たない                |
| シャオンダマ     | 通常シャオンダマを世界内へ出現させる  |

Playerへの追従方法や位置関係の詳細は[ラジクジラ｜追従・浮遊](./follow-and-floating.md)、戦闘中の存在・表示制御の詳細は[ラジクジラ｜Gameplayライフサイクル](./gameplay-lifecycle.md)を正本とします。

拠点の[演奏広場](/spec/hub/performance-plaza)では、設定した曲と行動でラジクジラが一人で演奏します。共有と戦闘での設定利用は、当面の広場の完成条件には含めません。

## 主要システムとの関係

| システム         | ラジクジラとの関係                                                                                                         |
| ------------ | ----------------------------------------------------------------------------------------------------------------- |
| Player       | 初期はPlayer周辺へ自律追従する。行動設定はストーリークリア後に解放する。行動再生をPlayer Stateには含めない |
| ゲーム進行・行動設定 | ゲーム進行が設定解放状態を提供し、設定側が曲・パターンの順序・継続小節数等を行動再生へ渡す。詳細は[行動パターンと設定解放](./behavior-patterns.md)を正本とする |
| 演奏広場 | 広場の音楽・行動・シャオンダマ演出の開始と終了を管理する。Battleとは別の実行単位とする。詳細は[演奏広場](/spec/hub/performance-plaza)を正本とする |
| BGM          | 通常シャオンダマについて「何を・いつ・何個生成するか」を決定する生成ロジック側の責務を持つ。詳細は[BGM→シャオンダマ生成仕様](../bgm/bgm-make-syaonndama.md)を正本とする            |
| MusicChart   | NoteEventなど、シャオンダマ生成に使用する音楽情報を管理する。ラジクジラ自身はMusicChartを管理・解析しない。詳細は[MusicChart](../bgm/bgm-music-chart.md)を正本とする   |
| Spawn System | BGM側で決定された生成内容を生成要求として下流へ渡す                                                                                       |
| ラジクジラ        | 生成要求を受け取り、通常シャオンダマを世界内へ出現させる。詳細は[ラジクジラ｜シャオンダマ生成](./shaondama-spawning.md)を正本とする                                   |
| シャオンダマ       | 世界内へ出現した後の存在・浮遊・Lifetime・選択等を担当する。生成後の仕様は[シャオンダマ](../shaondama-music/)カテゴリを正本とする                                  |
| Charge       | 生成済みのシャオンダマをPlayerが扱う側のシステムであり、ラジクジラはCharge判定を行わない。詳細は[Playerアクション｜チャージ](../player/player-action-charge.md)を正本とする |
| AttackEvent  | BGM側で管理されるシステムであり、ラジクジラとは直接接続しない。詳細は[AttackEvent](../bgm/bgm-attack-event.md)を正本とする                               |

## ラジクジラカテゴリのページ構成

ラジクジラに関する詳細仕様は、責務ごとに以下のページへ分離します。

| ページ                                                       | 担当する仕様                      |
| --------------------------------------------------------- | --------------------------- |
| [ラジクジラ｜行動パターンと設定解放](./behavior-patterns.md) | 初期追従、ストーリークリア後の設定解放、曲に合わせた行動再生と接続境界 |
| [ラジクジラ｜追従・浮遊](./follow-and-floating.md)                   | Player追従・浮遊・位置補正            |
| [ラジクジラ｜シャオンダマ生成](./shaondama-spawning.md)                 | 生成要求の受信・背中からの出現・生成演出との境界    |
| [ラジクジラ｜Gameplayライフサイクル](./gameplay-lifecycle.md)          | 戦闘中の存在・非攻撃対象・Player死亡時の表示制御 |
| [ラジクジラ｜Animation・VFX・Sound](./animation-effects-sound.md) | ラジクジラ固有のAnimation・VFX・Sound |
| [ラジクジラ｜キャラクター・世界観](./character-worldbuilding.md)          | キャラクター設定・世界観                |

本ページでは、これらの詳細仕様を重複して管理せず、ラジクジラ全体の概要と責務境界のみを正本として扱います。

## 責務外

以下はラジクジラ概要およびラジクジラ本体が判断・管理する仕様ではありません。

| 項目                            | 正本・担当             |
| ----------------------------- | ----------------- |
| NoteEventの選択                  | BGM / MusicChart  |
| 対象Track                       | BGM / MusicChart  |
| MusicChartの管理・解析              | BGM / MusicChart  |
| 生成対象の決定                       | BGM側のシャオンダマ生成ロジック |
| 生成タイミングの決定                    | BGM側のシャオンダマ生成ロジック |
| 生成個数の決定                       | BGM側のシャオンダマ生成ロジック |
| AttackEvent                   | BGMカテゴリ           |
| Charge判定                      | Player / Charge   |
| 生成後のシャオンダマの浮遊・Lifetime・選択・消滅等 | シャオンダマカテゴリ        |
| PlayerのState                  | Playerカテゴリ        |
| PlayerのDead遷移                 | Player死亡仕様        |

ラジクジラはMusicChartを直接解析して生成タイミングを判断せず、AttackEventやChargeの成立判定にも関与しません。

また、ラジクジラが担当するのは**シャオンダマを世界内へ出現させるところまで**であり、出現後のシャオンダマ挙動はシャオンダマ側へ委譲します。

## 未決事項

本概要ページでは、新しい未決事項を定義しません。

行動パターンと設定解放、追従・浮遊、Spawn、Gameplayライフサイクル、Animation・VFX・Sound、キャラクター・世界観などに存在する未決事項は、それぞれの詳細ページで管理します。

そのため、追従速度・浮遊範囲・具体的なSpawn位置・制御移譲タイミング・Animation・VFX・SE・戦闘外での存在・世界観等について、本ページでは具体的な仕様を定めません。
