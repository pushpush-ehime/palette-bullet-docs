# ラジクジラ｜追従・浮遊

## 目的

本ページでは、Playerとラジクジラの空間的な関係、およびラジクジラ自身の浮遊・追従・位置補正について定義します。

本ページにおける「浮遊」は、**ラジクジラ自身がPlayer周辺をどのように漂い、追従するか**を指します。

生成後のシャオンダマの浮遊・Lifetime・消滅については、本ページでは扱いません。

本ページでは主に以下を扱います。

- Player周辺でのラジクジラの浮遊
- Player移動への追従
- Player急移動時の追従
- Playerから極端に離れた場合の位置補正
- 画面外での位置補正
- シャオンダマ生成中の追従
- Stage Geometryとの関係
- 浮遊・追従・位置補正に関する調整パラメータ

ラジクジラそのものの概要・基本仕様は `radiowhale/index.md`、シャオンダマ生成処理は `radiowhale/shaondama-spawning.md` を正本とします。

## 追従の基本方針

ラジクジラは、Playerから直接操作されず、**Player周辺を自律的に浮遊しながら追従する存在**とします。

基本方針は以下です。

- Player周辺を自由に漂う
- Playerに対する特定方向へ常時固定しない
- Playerの特定Socketへ固定しない
- Playerの移動に対して滑らかに追従する
- Playerとの距離が変化した場合も、原則として通常の追従処理によって適切な距離へ戻る
- 通常追従では対応できないほど極端に離れた場合のみ、位置補正を使用する

ラジクジラの追従はPlayerのStateとして扱いません。

また、追従はシャオンダマ生成と排他的な処理ではなく、生成処理の有無にかかわらず継続します。

## 通常時の浮遊

通常時、ラジクジラはPlayer周辺の特定位置へ固定されるのではなく、Player周辺を自由に漂います。

ラジクジラの位置は、

- Playerの右側
- Playerの左側
- Playerの背後
- 特定Socketの位置

などへ常時固定しません。

Playerを基準とした一定の周辺領域の中で、自律的に位置を取る構成とします。

ただし、以下の具体値は現時点では確定していません。

- 浮遊範囲
- Playerに対する高さ
- 浮遊速度

これらは固定仕様ではなく、Gameplay上の見え方や操作性を確認しながら調整するパラメータとして扱います。

通常浮遊に伴う具体的なAnimation表現については `radiowhale/animation-effects-sound.md` で扱います。

## Player移動時

Playerが通常移動している間、ラジクジラはPlayerの移動に合わせて滑らかに追従します。

Playerの位置が変化した際に、ラジクジラをPlayerの特定位置へ瞬間的に固定し直すのではなく、ラジクジラ自身の移動によってPlayer周辺へ追従することを基本とします。

追従中も、通常時の自由な浮遊という性質は維持します。

具体的な追従速度やPlayerとの距離は調整パラメータとし、正式値は現時点では確定しません。

## Player急移動時

Playerがダッシュなどによって急速に移動した場合も、まずは通常の追従処理によって対応します。

Playerが急移動したことだけを理由として、即座にラジクジラをワープ・瞬間移動させる仕様にはしません。

基本的な処理は以下とします。

1. Playerが急速に移動する
2. ラジクジラは通常の追従処理を継続する
3. 通常追従によってPlayer周辺へ戻る
4. 通常追従では対応できないほど距離が開いた場合のみ位置補正を検討する

通常追従から位置補正へ切り替える具体的な距離は未決です。

## 距離が極端に離れた場合

Playerとラジクジラの距離が、通常の追従処理だけでは適切な位置関係へ戻れないほど極端に離れた場合は、位置補正を行います。

位置補正は通常の追従処理を置き換える常用処理ではなく、**極端な距離差を解消するための補助処理**として使用します。

そのため、Playerとの距離が一時的に広がっただけでは位置補正せず、まず通常追従を優先します。

位置補正を開始する具体的な距離は現時点では未決とし、調整パラメータとして扱います。

## 画面外での位置補正

位置補正を行う場合は、Playerから見える場所でラジクジラが不自然に瞬間移動する表現を避けるため、**Playerの画面外で位置補正を行う**ことを基本方針とします。

位置補正によって、極端に離れたラジクジラを再びPlayer周辺へ戻します。

ただし、以下は現時点では未決です。

- 画面外であることを判定する具体的な方法
- 補正先となる具体的な位置
- 補正を開始する距離
- 補正前後の具体的な移動処理

これらの具体的な判定方法・アルゴリズムは、本ページでは現時点で確定しません。

## シャオンダマ生成中の追従

ラジクジラは、**シャオンダマ生成中であってもPlayerへの追従を継続します。**

追従とシャオンダマ生成は、どちらか一方しか実行できない排他的なStateとして設計しません。

```text
Player追従
    ＋
シャオンダマ生成
```

のように、両方の処理が同時に成立できる構成とします。

そのため、シャオンダマ生成の開始を理由として、

* ラジクジラの追従を停止する
* ラジクジラを固定位置へ移動させる
* 追従Stateから生成Stateへ排他的に切り替える

といった仕様にはしません。

本ページが正本として扱うのは、**生成中にも追従を継続すること**までです。

生成要求の受信、背中からの出現、複数生成、シャオンダマ側への制御移譲など、シャオンダマ生成そのものの仕様は `radiowhale/shaondama-spawning.md` で扱います。

## Stage Geometryとの関係

ラジクジラの浮遊・追従では、壁やその他のStage Geometryとの関係を考慮する必要があります。

ただし、現時点ではStage Geometryに対する具体的な干渉方式は確定していません。

そのため、以下については未決とします。

* 壁との衝突をどのように扱うか
* Stage Geometryをどのように回避するか
* Geometryとの干渉時に追従位置をどのように補正するか

Stage Geometryへの具体的な対応方式を推測で固定せず、実装・検証を通して決定します。

## 調整パラメータ

浮遊・追従・位置補正に使用する具体値は、現時点では正式値を確定せず、調整可能なパラメータとして扱います。

| 項目    | 用途                            | 状態      |
| ----- | ----------------------------- | ------- |
| 浮遊範囲  | Player周辺でラジクジラが自由に漂える範囲       | 未決・調整対象 |
| 高さ    | Playerに対するラジクジラの高さ            | 未決・調整対象 |
| 追従速度  | Player移動へ追従する際の速度             | 未決・調整対象 |
| 浮遊速度  | 通常時にPlayer周辺を漂う速度             | 未決・調整対象 |
| 補正距離  | 通常追従から位置補正を検討する距離             | 未決・調整対象 |
| 画面外判定 | 位置補正をPlayerから見えない状態で行うための判定条件 | 未決・調整対象 |

これらは仮値を使用して実装・検証を進めることができますが、仮値を正式仕様として扱いません。
