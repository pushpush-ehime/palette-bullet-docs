# ゲームプレイサイクル

## 目的

本ページでは、ラジクジラのGameplay上の存在状態・表示制御を定義します。

本ページでは主に以下を扱います。

- 戦闘中のラジクジラの存在
- Gameplay上の非攻撃対象としての扱い
- HP・Damage・Deadの扱い
- Player死亡時の表示制御
- Retry・戦闘再開始との関係
- 戦闘終了後および戦闘外での存在

Playerへの追従・浮遊・位置補正については `follow-and-floating.md`、Player自身の死亡処理については `../player/player-death.md` を正本とします。

## 戦闘中の存在

戦闘中は、ラジクジラが基本的に存在します。

また、ラジクジラ不在の戦闘は基本的に作りません。

ただし、これは「すべての戦闘で例外なく必ず存在する」という絶対条件ではありません。

ラジクジラのPlayer追従や浮遊、位置補正などの具体的な移動処理は本ページでは扱わず、`follow-and-floating.md` を正本とします。

## Gameplay上の非攻撃対象

ラジクジラは、Gameplay上の攻撃対象として扱いません。

敵との関係について、以下を確定仕様とします。

- ラジクジラは敵のTargetにならない
- 敵から攻撃される対象として扱わない

Enemy側のTarget選定アルゴリズムそのものは本ページでは定義しません。

## HP・Damage・Deadを持たない

ラジクジラは、戦闘対象としてのHP・Damage・Deadを持ちません。

| 項目 | 仕様 |
| --- | --- |
| HP | 持たない |
| Damage | 持たない |
| Dead | 持たない |

そのため、ラジクジラに対して、

- HPを減少させる
- Damageを受けさせる
- HPが0になったことで死亡させる
- `Dead` Stateへ遷移させる

といった処理は行いません。

## Player死亡時

Player死亡演出中は、ラジクジラを非表示にします。

この非表示は、ラジクジラ自身の死亡を意味するものではありません。

```text
Player死亡
↓
Player死亡演出中
↓
ラジクジラを非表示
```

Player死亡時も、ラジクジラにHP・Damage・Deadを発生させません。

つまり、

```text
Playerが死亡する
≠
ラジクジラが死亡する
```

という関係です。

本ページが正本として扱うのは、**Player死亡演出中にラジクジラを非表示にすること**までです。

Player自身の、

* Deadへの遷移
* 死亡処理
* Retryへ至る処理

については `../player/player-death.md` を正本とし、本ページでは定義しません。

また、Player死亡時の具体的な消失Animation・VFX・Soundについては `animation-effects-sound.md` で扱います。

## Retry・戦闘再開始との関係

Retryなどによって戦闘を再開始した場合は、再び「戦闘中はラジクジラが基本的に存在する」という本ページの原則に従います。

ただし、Retry時の具体的な再出現方法は未決です。

現時点では、以下を定義しません。

* 再表示する具体的なタイミング
* 再Spawnするかどうか
* 再出現位置
* 既存インスタンスを再利用するか
* 新しいインスタンスを生成するか

## 戦闘終了時

戦闘終了によって、ラジクジラを死亡扱いにはしません。

戦闘終了後のラジクジラの存在については、戦闘外での存在仕様に依存します。

現時点では戦闘外でも常時同行するかが未決であるため、戦闘終了後の具体的な存在・表示方法も本ページでは確定しません。

## 戦闘外での存在

戦闘外でもラジクジラが常時Playerへ同行するかは未決です。

この仕様は世界観担当へ保留します。

そのため、現時点では以下を確定しません。

* 拠点でも常時同行する
* Gameplay外では非表示になる
* Scene間で常に同じラジクジラを維持する

キャラクター・世界観上のPlayerとの関係については `character-worldbuilding.md` で扱います。

## 未決事項

以下は現時点では未決です。

* 戦闘外でも常時同行するか

  * 世界観担当へ保留
* Retry時の具体的な再出現手順
* Scene遷移時の生成・破棄方法

Scene遷移について、

* Persistent化する
* Scene遷移時に破棄する
* Scene遷移後に再生成する

などの具体的な実装方式は、現時点では確定しません。
