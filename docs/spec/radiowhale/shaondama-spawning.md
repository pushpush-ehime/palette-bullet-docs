# ラジクジラ｜シャオンダマ生成

## 目的

本ページでは、**ゲームシステム側でシャオンダマの生成が決定した後、ラジクジラを介して世界内へ出現し、シャオンダマ側へ制御を移譲するまで**を定義します。

ラジクジラは、シャオンダマの生成対象・生成タイミング・生成個数を判断しません。

生成に関する責務は、次のように分離します。

```text
BGM / MusicChart
「何を・いつ・何個生成するか」を決定
        ↓
Spawn System
生成要求
        ↓
ラジクジラ
生成要求を世界内の出現へ変換
        ↓
シャオンダマ
生成後の存在・浮遊・Lifetime・選択等を担当
```

本ページでは、このうち**ラジクジラが生成要求を受け取り、シャオンダマを背中側から世界内へ出現させる範囲**を正本として扱います。

## ラジクジラが担当する生成範囲

ラジクジラが担当する範囲は、外部のSpawn Systemから生成要求を受け取ってから、シャオンダマを世界内へ出現させ、シャオンダマ側へ制御を移譲するまでです。

基本的な流れは以下です。

```text
外部Spawn System
        ↓
生成要求
        ↓
ラジクジラ
        ↓
少し姿勢を変更
        ↓
背中側からシャオンダマを出現させる
        ↓
シャオンダマ側へ制御を移譲
```

ラジクジラ自身がMusicChartやNoteEventを解析して生成対象や生成タイミングを決定することはありません。

また、ラジクジラが担当するのは**シャオンダマを生み出すところまで**です。

世界内へ出現した後のシャオンダマの挙動は、[シャオンダマ](../shaondama-music/)カテゴリを正本とします。

## 生成要求の受信

ラジクジラは、外部のSpawn Systemからシャオンダマの生成要求を受け取ります。

生成要求を受信した時点では、ラジクジラ側で、

* 対象Trackを選択する
* NoteEventを選択する
* 生成する個数を決定する
* 生成タイミングを決定する
* BGMとの同期位置を計算する

といった判断は行いません。

これらはBGM / MusicChart側の責務です。

ラジクジラは、上流システムですでに決定された生成内容を、**世界内での出現へ変換する役割**を持ちます。

## 生成要求に含まれる情報

生成要求の具体的なフィールド構成は、現時点では本ページで定義しません。

生成要求として下流へ渡すデータの詳細は、BGM側の生成仕様を正本とします。

本ページでは、ラジクジラが生成要求を受信した後に、その要求内容をもとに世界内への出現処理を行うことのみを定義します。

ラジクジラ側で生成要求を補完するためにMusicChartを再解析したり、生成対象・生成個数・生成タイミングを再決定したりしないものとします。

## 生成元

シャオンダマは、**ラジクジラの背中側から世界内へ出現します**。

ラジクジラは生成時に少し姿勢を変更し、その後、背中からシャオンダマを吹き出す形で出現させます。

本ページで定義するのは、

* 生成時に姿勢変更が発生すること
* 背中側がシャオンダマの出現元となること

までです。

具体的なAnimation、VFX、SE、鳴き声などの演出内容は、本ページでは定義しません。

これらの詳細は[ラジクジラ｜Animation・VFX・Sound](./animation-effects-sound.md)を正本とします。

また、背中のどの位置を具体的なSpawn位置とするかは未決です。

## 単体生成

1体のシャオンダマを生成する要求を受けた場合も、ラジクジラは通常の生成処理として扱います。

```text
生成要求
        ↓
ラジクジラの姿勢変更
        ↓
背中側からシャオンダマを出現
        ↓
シャオンダマ側へ制御移譲
```

生成対象・生成タイミングをラジクジラ側で再判断することはありません。

また、生成後の浮遊・Lifetime・消滅・選択対象としての挙動はラジクジラ側では管理しません。

## 複数生成

複数のシャオンダマを生成する要求についても、ラジクジラを介して世界内へ出現させます。

複数生成の場合も、

* 生成する個数の決定
* 生成対象の決定
* 生成タイミングの決定

はラジクジラ側の責務ではありません。

ラジクジラは、受け取った生成要求に従ってシャオンダマを背中側から出現させます。

複数生成時の具体的な演出方法や、各シャオンダマを視覚的に出現させる間隔は未決です。

## Gameplayロジックと表示タイミングの分離

**Gameplay上の生成成立と、ラジクジラからシャオンダマが視覚的に出現するタイミングは、区別して扱います。**

ラジクジラの姿勢変更や背中から吹き出す表現は、上流で決定された生成内容を世界内へ表現するための処理です。

そのため、

```text
BGM / MusicChartによる生成内容の決定
```

と、

```text
ラジクジラによる視覚的な世界内出現
```

を同一の責務として扱いません。

具体的なAnimationやVFXの長さによって、BGM側の生成対象・生成個数・生成タイミングを再決定することもありません。

ただし、

* Gameplay上でシャオンダマを生成済みとみなす具体的なタイミング
* 視覚的な出現との具体的な時間関係
* 視覚的にはまだ出現していないが、論理上生成済みのシャオンダマをPlayerが選択可能か

については未決です。

特に、**論理上生成済みで視覚的にはまだ出現していないシャオンダマをPlayerが選択可能かどうか**は、実装前に決定する必要があります。

## 生成中の追従

シャオンダマ生成とPlayer追従は、排他的なStateとして扱いません。

ラジクジラは**シャオンダマ生成中も通常のPlayer追従を継続します**。

生成処理を開始したことを理由として、Playerへの追従を停止しません。

ただし、

* 追従速度
* Playerとの距離
* 浮遊範囲
* 画面外での位置補正
* Stage Geometryとの関係

などの具体的な追従仕様は、本ページでは定義しません。

これらは[ラジクジラ｜追従・浮遊](./follow-and-floating.md)を正本とします。

## シャオンダマ側への制御移譲

ラジクジラが担当するのは、シャオンダマを世界内へ出現させ、シャオンダマ側へ制御を移譲するところまでです。

制御移譲後の、

* 浮遊
* Lifetime
* 消滅
* 選択対象としての通常挙動

などは、[シャオンダマ](../shaondama-music/)カテゴリの責務です。

ラジクジラは、出現後のシャオンダマを自身の生成処理の一部として継続管理しません。

ただし、**どのタイミングをもってシャオンダマ側へ制御を移譲したとみなすか**は未決です。

## BGM生成システムとの境界

シャオンダマ生成について、BGM側とラジクジラ側の責務は明確に分離します。

| 項目                      | 正本・担当            |
| ----------------------- | ---------------- |
| 対象Track                 | BGM / MusicChart |
| NoteEvent選択             | BGM / MusicChart |
| `1 NoteEvent = 1シャオンダマ` | BGM側のシャオンダマ生成仕様  |
| `InitialTargetCount`    | BGM側のシャオンダマ生成仕様  |
| `MinimumLeadTime`       | BGM側のシャオンダマ生成仕様  |
| 生成対象の決定                 | BGM側のシャオンダマ生成仕様  |
| 生成個数の決定                 | BGM側のシャオンダマ生成仕様  |
| 生成タイミングの決定              | BGM側のシャオンダマ生成仕様  |
| BGMとの同期                 | BGM / MusicChart |
| 生成要求                    | Spawn System     |
| 生成要求の受信                 | ラジクジラ            |
| 世界内への出現                 | ラジクジラ            |
| 背中側からの出現                | ラジクジラ            |
| 出現後のシャオンダマ挙動            | シャオンダマカテゴリ       |

BGM側の生成ロジックについては、[BGM→シャオンダマ生成仕様](../bgm/bgm-make-syaonndama.md)を正本とします。

MusicChartおよびNoteEventなどの音楽データ構造については、[MusicChart](../bgm/bgm-music-chart.md)を正本とします。

ラジクジラはこれらの生成ロジックを複製せず、**上流で決定された生成要求を世界内でどう出現させるか**だけを担当します。

AttackEventは[AttackEvent](../bgm/bgm-attack-event.md)、生成済みシャオンダマをPlayerが扱うChargeは[Playerアクション｜チャージ](../player/player-action-charge.md)をそれぞれ正本とし、ラジクジラの生成処理とは直接接続しません。
