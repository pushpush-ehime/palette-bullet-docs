# 拠点の町

## 目的

拠点を複数の機能を持つ町として構成し、施設の採用状況と制作時に守る方針を整理します。ギルドは町の機能の一つです。

施設を置く決定と、全機能の実装完了・寸法・制作順の決定は区別します。

## 確定した施設

| 施設 | 役割・方針 | 詳細 |
|---|---|---|
| 冒険者ギルド | 人と話し、依頼を受ける場所。話し合いを通じて依頼や挑戦できるバトルが増える | 本ページのギルド仕様 |
| 調律工房 | Mode／Conductのチューニングを行う場所 | 操作・構成の意味は[Mode構成](/spec/player/mode-configuration-and-effectors)等を正本とする |
| 試走スペース | 調整した内容や動きを試すための場所 | 試せる項目、設備、判定方法は未決 |
| レコード販売所 | レコードを販売する場所 | 品揃え、購入方式、ゲーム内での曲の利用方法は未決 |
| 演奏広場 | ラジクジラが設定した曲と行動で自動演奏し、Playerが鑑賞する場所 | [演奏広場](./performance-plaza.md) |

ラジクジラの行動設定は[行動パターンと設定解放](/spec/radiowhale/behavior-patterns)を正本とします。行動設定画面をどの施設から開くかは未決です。

## 候補・条件付きのもの

| 項目 | 状態 |
|---|---|
| 楽器・雑貨店 | 有力候補。設置は未確定 |
| ラジクジラのレベルアップ | 開発状況に応じて採用を検討する。必須機能にはしない |
| ラジクジラの専用の居場所 | 位置・大きさ・常設の必要性は未決 |

演奏広場でラジクジラが演奏することは確定していますが、町の中で常時同行することや、専用の居場所を設けることは同じ決定ではありません。

## 冒険者ギルド

酒場のように人が集まり、席で会話できる冒険者ギルドとします。

入口から見た配置方針は次のとおりです。

- 正面奥にギルド職員の受付を置きます。受付でもクエストを受注できます。
- 右側にクエスト受注用の掲示板を置きます。
- 左側に2階へ上がる階段を置きます。
- 1階に複数の席を設け、会話や談笑の場にします。
- 2階にも人が談笑できる場所を設けます。

掲示板と受付の具体的な操作画面、依頼を解放する会話条件、同時に受注できる数等は未決です。階段、2階の床面積、席数、通路幅を仮の図から正式寸法へ読み替えません。

## 見た目と配置の方針

- 音楽にまつわる機能や人々の暮らしを表現します。
- 町全体にシャボン玉の要素を取り入れます。
- 鮮やかな色彩を使用します。
- 大きすぎない拠点を目指し、必要な場所へ行き来しやすくします。

制作イメージとして「シャボン玉が浮かぶ、鮮やかな音楽の町」を用います。建物の正確な配置、屋根の色分け、大木、泡の量、灯り等の個別表現は検討段階です。

曲の設定（モード）に応じてステージのライティングを変える案は、[演奏広場](./performance-plaza.md)の「検討メモ：モードに応じたライティング」に記録します。採用や照明の変化する範囲は未決とし、町の景観案を考える際の参考にします。

演奏広場の演出に使うシャオンダマと、町の景観としてのシャボン玉は、同じGameplay機能を持つものとして扱いません。景観の泡を自動的に戦闘の選択対象へ含めません。

## 開発範囲

拠点の最初の演奏機能は、[演奏広場](./performance-plaza.md)に定める「ラジクジラが一人で自動演奏できること」までとします。オンライン共有を完成条件にはしません。

[Battleプロトタイプ](/spec/game/prototype)は拠点を経由しない独立した検証範囲です。本ページの施設一覧を、既存のBattleプロトタイプに必要な実装一覧として追加しません。

## 未決事項

- 町の寸法、施設間の距離、通路幅、高低差、移動できる範囲
- 各建物の外観、ギルドの席数・階段・2階の詳細
- ギルドの依頼解放条件、受注UI、ステージへの出発方法
- 試走スペースで確認できる機能と設備
- レコードの品揃え、価格・入手方法、曲の利用範囲
- ラジクジラの行動設定画面を開く場所
- 楽器・雑貨店の採否
- ラジクジラのレベルアップ機能の採否と専用の居場所
- 各施設の制作順、同時に実装する範囲、各担当への割当
