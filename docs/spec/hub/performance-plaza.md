# 演奏広場｜ラジクジラの自動演奏

## 目的

拠点の演奏広場で、ラジクジラが設定された曲と行動パターンに合わせて動き、シャオンダマを出しながら一人で演奏できるようにします。

Playerは事前の設定と鑑賞で参加します。本番中にPlayerがラジクジラを直接操作したり、演出操作を続けたりしなくても演奏が成立することを、当面の完成条件とします。

## 確定事項

- 演奏広場を拠点の施設として設置します。
- ラジクジラが、設定された曲と行動パターンで自動演奏します。
- Playerは演奏を鑑賞し、設定を変えて再び試せる構成とします。
- **Playerによる行動設定はストーリークリア後に解放します。** チュートリアルの初期追従を含む詳細は[行動パターンと設定解放](/spec/radiowhale/behavior-patterns)を正本とします。
- 演奏広場の完成に、戦闘での設定利用やクリック試遊は必須にしません。
- 音楽・設定の共有、他のPlayerとの同時参加は必須にしません。

行動設定の解放時点と、広場の建物への入場・鑑賞をいつ利用可能にするかは別の条件です。後者は未決とし、行動設定の解放条件から推測して固定しません。

## Playerから見た流れ

1. 利用可能な曲と、設定済みの行動を用意します。
2. 広場で演奏を開始します。
3. 曲の進行に合わせてラジクジラが行動パターンを実行し、シャオンダマが現れます。
4. Playerはその演奏を鑑賞します。
5. 演奏を終え、再び開始できます。設定解放後は、事前に設定を変更して別の演奏を試せます。

初期の開発確認は、用意済みの曲と既定の追従パターンで行えます。自由な軌道編集、任意音源のアップロード、全ストーリーの実装を、この最初の接続確認の前提にはしません。製品での設定解放条件は変更しません。

## 演奏の接続関係

```text
ストーリー進行の解放状態
        ↓
ラジクジラの行動設定
        ↓
曲と設定済み行動を演奏開始時に受け渡す
        ↓
広場の演奏管理
├─ 音楽再生・音楽位置
├─ 音楽位置に合わせたラジクジラの行動再生
└─ 生成内容の決定 → 出現処理 → シャオンダマの演出
        ↓
演奏終了・次の演奏を開始できる状態
```

| 担当範囲 | 広場で担当すること | 担当しないこと |
|---|---|---|
| ゲーム進行 | 行動設定の解放状態を提供する | 音楽の再生位置や移動軌道の算出 |
| 行動設定 | 解放可否に応じた編集と、設定済みデータの提供 | 演奏中の時計やBattle結果の管理 |
| 広場の演奏管理 | 使用する曲・設定の受け渡し、演奏の開始・終了・再開始、各担当の処理の終了確認 | ストーリークリアの独自判定、Battle開始・勝敗判定 |
| BGM／音楽進行 | 音楽再生、音楽位置の供給、音楽側の生成内容・時刻の決定 | ラジクジラの世界内移動の決定 |
| ラジクジラの行動再生 | 音楽位置と選択された行動から、移動と区間進行を実行する | NoteEventや生成個数の再決定 |
| ラジクジラの出現処理 | 現在の位置からシャオンダマを出現させる | 出現後の浮遊・寿命の継続管理 |
| シャオンダマの演出 | 出現後の見た目・動き・終了を扱う | 広場でのDamage、Charge成立、AttackEvent結果の確定 |
| Stage／Camera／UI | 演奏位置、見通し、開始・終了操作と表示 | 音楽位置や行動設定の独自進行 |

行動側の共通契約は[行動パターンと設定解放](/spec/radiowhale/behavior-patterns)に従います。具体的なクラス配置・メソッド名・データ形式は、接続する担当範囲を保ったうえで実装設計に委ねます。

## Battle処理との境界

広場演奏はBattleではありません。音楽位置、行動再生、出現の視覚表現を再利用する場合も、広場の演奏とBattleの実行状態を区別します。

- 広場の演奏単位で、現在の曲・行動進行・演出を識別します。識別子の形式は未決です。
- Battle開始Ready、Enemy Ready、戦闘用の最低保証補充、AttackEventの発火、Charge、Damage、Clear／Game Overは広場演奏の開始条件に含めません。
- 広場の演出用シャオンダマを、戦闘の選択可能数やReservedの集計へ含めません。
- Battle IDを前提にする生成APIへ、広場からダミーのBattle IDを渡して動作させる方式は採りません。共通化する処理と、広場／Battleそれぞれの受付境界を分けます。
- 演奏が終了した後に届く処理や通知を、次の演奏や後のBattleに適用しません。

[BGMとGameplayの接続](/spec/bgm/bgm-gameplay-connection)や[ラジクジラの生成仕様](/spec/radiowhale/shaondama-spawning)のBattle専用の判定を、広場向けに無条件で緩めません。

## 開始・終了と再開始

演奏開始時は、対象曲と設定済みの行動を使用できる状態にしてから、同じ曲の開始基準で音楽と行動の進行を開始します。

演奏終了時は、その演奏に属する新しい行動進行・生成・音を停止し、進行中の演出を終了できるようにします。次の開始では前の曲の区間進行や未完了の要求を引き継ぎません。

具体的な開始演出、終了後に追従へ戻るか、余韻を残すか、ラジクジラをどこへ置くかは未決です。これらを理由に、同じ曲が重複して流れたり、終了済みの演出が次の演奏へ混ざったりしないようにします。

## Stage制作で確保するもの

- ラジクジラが演奏する位置と、行動パターンを試せる空間
- シャオンダマの出現と動きが見える前方・上方の空間
- Playerが鑑賞できる位置と、画面の見通し
- 演奏位置と家具・観客等の配置が干渉しない構成

具体的な広さや高さ、カメラ形式、ラジクジラの大きさは未決です。仮のPlayer・ラジクジラ・カメラ・泡を置いて確認し、コンセプト画の比率を正式寸法として固定しません。

## 検討メモ：モードに応じたライティング

曲の設定（モード）に応じて、演奏広場／拠点のステージのライティングが変化する仕組みを検討します。音楽・ラジクジラの動き・シャオンダマに照明を組み合わせ、アピール審査のように演奏を見せる楽しさを高める案です。

- 照明の色・明るさ・照らす方向などを変える表現が候補です。具体的な色とモードの対応は未決です。
- どのモード情報を参照するか、曲中の切替や拍・小節に同期するか、ステージ周辺だけか町全体にも反映するかは未決です。
- 正式採用、実装時期、設定方法、照明の制御担当・接続方法は未決です。当面の単独自動演奏の完成条件には追加しません。

これは今後の景観・演出を考えるためのメモです。コンテストの開催・採点・共有機能を確定するものではなく、既存の[Mode構成](/spec/player/mode-configuration-and-effectors)やBattle側の適用規則も変更しません。

## 当面の完成条件

- 設定済みの曲を広場で再生できる。
- ラジクジラが設定された行動を曲に合わせて自動実行する。
- シャオンダマが出現し、音と動きが組み合わさった演奏として鑑賞できる。
- 演奏中にPlayerが操作し続けなくても成立する。
- 演奏を終了し、同じ設定で再び開始できる。

これは演奏広場の機能に対する完成条件です。[Battleプロトタイプの完成条件](/spec/game/prototype)へ、拠点・ストーリー・行動設定編集を追加するものではありません。

- 追従以外の行動パターンとシャオンダマの具体的な配り方
- 舞台の寸法、ラジクジラの移動範囲、家具・観客・カメラの配置
- 開始前の準備時間、曲のループ、演奏中の設定変更の扱い
- 演奏終了後のラジクジラの位置・追従・表示と演出の余韻
