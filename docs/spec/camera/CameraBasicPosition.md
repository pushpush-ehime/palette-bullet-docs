# カメラの基準配置

## ページ概要

『Palette Bullet』における通常状態（非ダッシュ・非エイム・非ドローモード）のカメラの配置を定義する。
注視点・基準距離・オフセット・画角（FOV）・near clipの基本値を扱い、**カメラ関連の基準値はすべて本ページを正とする**。

## 目的

- キャラクターを画面中央からずらす「右肩越し」配置により、TPSとしての前方視認性とレティクル周辺の視界を確保する
- 画面酔いを防ぎつつ状況把握しやすい画角を定める
- ダッシュ時・エイム時など状態別カメラ仕様の「基準値」となる数値を1か所に集約する

## プレイヤーから見た挙動

- 自分のキャラクターは画面のやや左に表示され、右肩の上越しに前方が見える
- キャラクターが画面中央のレティクルや前方の敵・シャオンダマを隠すことはない
- 通常移動中、カメラの距離・画角は一定に保たれる
- 下を向いても、カメラが地面に潜って何も見えなくなることはない

## 詳細仕様

### 注視点（Pivot）

カメラが回る中心となる点を注視点と呼ぶ。**注視点の定義は本ページを正とする。**

- 注視点は**キャラクターの頭の少し上**に置く
- 注視点には**オフセットX（右）・オフセットY（上）を適用する**。つまり「右肩越し」は注視点側のずらしで表現し、カメラは常に注視点から後方へ基準距離だけ離れた直線上に置く
- この定義により、注視点からカメラ位置へ引いた線の上に必ずカメラが存在する。[カメラの障害物処理](/spec/camera/collision) はこの線を判定に使う

### 配置と画角

- カメラはキャラクターの後方に配置し、真後ろ中央ではなく右側へオフセットした「右肩越し（オーバーショルダー）」配置とする
- 画角は**水平FOV 85度**を基準とする（Unityの `Camera.fieldOfView` は垂直FOVのため、16:9換算で**垂直約54.5度**を設定する）
- 一般的なTPSより極端に狭い画角にしない（画面酔い防止・状況把握のため）
- 基準距離（注視点からカメラまでの直線距離）は未決。実装時はInspectorで調整可能にし、決定値をこのページに反映する
- オフセットの軸はUnity座標系に準拠する:

| 軸 | 方向 | 設定方針 |
|---|---|---|
| X軸（左右） | 右方向＋ | 右へずらす（キャラクターが画面やや左に寄る） |
| Y軸（上下） | 上方向＋ | 上へずらす（頭上越しに前方が見える） |
| Z軸（前後） | 前方＋ | `0` 固定（前後は基準距離側で制御する） |

- キャラクターモデルが変わった場合、本ページの全パラメータは再調整が必要

### near clip

- near clipは **0.1** とする（Unityの既定値0.3から変更する）
- 理由: [カメラの障害物処理](/spec/camera/collision) で必要になる判定の太さは、near平面の外接半径から決まる。既定値0.3のままだと最大FOV時に約0.51mの太さが必要になり、そこそこ広い部屋でも判定が壁に当たって寄りっぱなしになる。0.1なら約0.17mで済む

### 見下ろし時の基準距離（ピッチ連動）

見下ろすほどカメラは注視点より下に回り込むため、**ピッチ制限だけでは地面へのめり込みを防げない**。
見下ろし限界の-45度では、基準距離4mならカメラは注視点から真下へ約2.83m下がり、注視点が頭の高さでも地中に入る。

- **見下ろすほど基準距離を短くする**ことで、-45度の時点でも地面に接触しない配置を作る
- ピッチと基準距離の対応（カーブ）はInspectorで調整可能にする
- ここで防ぎきれなかった分だけを [カメラの障害物処理](/spec/camera/collision) が拾う。障害物処理に全面的に任せない（下を向くたびにカメラが寄って後頭部で画面が埋まるため）

### 更新タイミング

- カメラの位置・回転の更新は **LateUpdate** で行い、**Player系の移動更新より後**に実行する
- Updateで更新するとキャラクターの移動より前に走るフレームが混ざり、キャラクターが1フレーム遅れて見えてジッターの原因になる
- この規約はカメラ関連の全ページに共通して適用する

## 状態別の挙動

本ページの値は「通常状態」のもの。以下の状態では別ページの定義が本ページの値を上書きする。

- ダッシュ時: [カメラの基準配置（ダッシュ時）](/spec/camera/CameraBasicPosition-dash)
- ドローモード中: [ドローモード時のカメラ](/spec/camera/draw-mode)
- エイム（覗き込み）時: [エイム時のカメラ](/spec/camera/aim)
- 障害物と干渉するとき: [カメラの障害物処理](/spec/camera/collision)

## 他システムとの接続

- カメラの回転操作は [カメラの通常動作](/spec/camera/CameraFreeRot) を参照（注視点そのものの定義は本ページが持つ）
- プレイヤーの移動・ダッシュ（Player系）はこのカメラの向きを基準に入力方向を解釈する
- Player系の状態変化（ダッシュ開始・終了、ドローモード開始・終了、強制リセット）の通知を受けて、各状態別ページの値へ切り替える

## 例外・禁止事項

- 本ページの数値をコードにハードコードしない。すべて `[SerializeField]` または ScriptableObject でInspector調整可能にすること
- 状態別ページが値を定義している間は、本ページの基準値を直接参照しない（ブレンド元としてのみ使う）。ただし [カメラの障害物処理](/spec/camera/collision) は基準距離を上限とする減算フィルタとして働くため、この制限の対象外とする
- カメラ更新をUpdateで行わない（LateUpdateで、Player移動より後に実行する）

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| 注視点 | キャラクターの頭の少し上（オフセットX・Yを適用した点） | 仮仕様 |
| 標準FOV | 水平85度（垂直換算 約54.5度） | 🟡仮値 |
| near clip | 0.1 | 🟡仮値 |
| 基準距離 | 未決 | 🔴未決 |
| オフセットX（右方向） | 未決 | 🔴未決 |
| オフセットY（上方向） | 未決 | 🔴未決 |
| オフセットZ（前後） | 0（基準距離で制御） | 仮仕様 |
| ピッチと基準距離の対応 | 見下ろすほど短くする（カーブは未決） | 🔴未決 |
| 更新タイミング | LateUpdate（Player移動より後） | 仮仕様 |

## 未決事項

- 基準距離（注視点からカメラまでの直線距離）の数値。**他のカメラ数値がこれに依存するため最初に決める必要がある**
- オフセット量（右方向X・上方向Y）の数値
- FOVの正式確定値（現仮値: 水平85度）
- ピッチと基準距離の対応カーブ（-45度で地面に接触しない値）
- キャラクターモデルの頭の高さが確定した後の、注視点の再調整
