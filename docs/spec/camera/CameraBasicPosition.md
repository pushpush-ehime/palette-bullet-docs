# カメラの基準配置

本ページでは、『Palette Bullet』における基本的なカメラの配置、距離、および画角について定義する。

## 1. 概要
キャラクターを画面中央に配置するのではなく、TPSとしての視認性を確保するため、「右肩越し」を基準としたオフセット配置を行う。
#### 担当者へ
担当者は以下のパラメータを調整して決定してください。
⚠モデルが変わるたびに変更する必要があります。

## 2. 基本パラメーター

### 2.1 画角（FOV - Field of View）…視界の範囲
* **標準FOV:** `85度` （※仮値→確定したら変更してね）
* **備考:** 画面酔い防止および状況把握のため、一般的なTPSより極端に狭くならない数値を基準とする。

### 2.2 基準距離（Distance / Target Arm Length）
* **標準距離:** `XXX [cm/m]` （※仮値→確定したら変更してね。キャラクターからカメラまでの直線距離）
* **備考:** ちょうどいい距離を見つけたら↑に書いて下さい！

## 3. カメラ位置オフセット（肩越し配置）

プレイヤーキャラクターが画面中央のレティクルや前方の視界を塞がないようにするための位置ずらし設定。

* **オフセット値（Offset）:**
  * **X軸（前後）:** `0` （※前後の距離は「基準距離」で制御する）
  * **Y軸（左右）:** `+YYY` （右方向へずらす。キャラクターが画面のやや左に寄る）
  * **Z軸（上下）:** `+ZZZ` （上方向へずらす。キャラクターの頭上越しに前方が見えるようにする）

## 4. 補足（状態変化について）
本ページで定義するパラメーターは「通常状態」のものである。
以下の状態へ移行した際のFOVや距離・オフセットの動的な変動については、別ページにて定義する。
* ダッシュ時（FOVの拡大など）
* エイム / スキル構え時（ズームイン、オフセットの変更など）
* 狭所・室内への進入時（距離の短縮など）
