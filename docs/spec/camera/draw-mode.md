# ドローモード時のカメラ

## ページ概要

ドローモード（スロー中にシャオンダマをなぞって繋ぐモード）中のカメラ挙動を定義する。
通常状態の [カメラの基準配置](/spec/camera/CameraBasicPosition) からの**差分のみ**を扱う。

本ページで定義するカメラ回転は、ドローモードのなぞり入力そのものを兼ねる。

## 目的

- 一人称視点と広い画角により、周囲のシャオンダマを大きく・多く見せる
- カメラを向けた先の玉を直接なぞれるようにし、狙う操作と見る操作を一致させる
- キャラクターの体で画面が塞がらないようにする

## プレイヤーから見た挙動

- ドローモードに入ると、視点がスッと自分の頭の位置まで寄って一人称になり、視界が広がる
- 自分のキャラクターは画面に映らなくなる
- 画面中央のレティクルを玉に合わせ、カメラを振って線を引いていく
- カメラを振れば背後の玉にも届く
- ドローモードを抜けると元の三人称視点に戻る
- スロー中でも、視点の切り替わりやカメラの振り心地の速さは通常と変わらないように見える

## 詳細仕様

視点はFPS（一人称）とする。カメラはキャラクターの頭の位置に置き、右肩越しのオフセットは適用しない。

- 画角は**水平FOV 100度**（16:9換算で**垂直約68度**）まで広げる。通常時の水平85度から+15度
- ドロー中はプレイヤーキャラクターのモデルを**非表示**にする（手・腕なども表示しない）
- **カメラ回転を有効にし、これをなぞり入力として使う**
  - 画面中央のレティクルが選択位置を表す
  - なぞり入力を保持したままカメラを振ると、レティクルが通過したシャオンダマが順に繋がる
  - 回転の制限・感度・軸反転の設定は [カメラの通常動作](/spec/camera/CameraFreeRot) の定義を継承する
- プレイヤーの移動は可能（統合仕様書 v3.2 §4.3.6・仮仕様）。カメラは通常どおり位置を追従する
- 視点の切り替えは短時間の補間で行う。肩越しの位置から頭の位置へカメラが寄り、同時にFOVが広がる
- 補間およびカメラ回転の入力処理は **unscaled time（実時間）** で行う。ドローモード中はスロー（0.2倍速）だが、見た目の速さと操作の追従性は変えない
- FOVは常に「現在値から、その時点の状態の目標値へ補間する」方式とする。状態が切り替わったときは目標値だけを差し替える（下記の競合を単純な規則で解決するため）
- ゲーム状態のリセット時など、補間を待たず即座に通常の三人称視点・通常FOVへ戻す経路も用意する

## 状態別の挙動

- **通常 → ドローモード**: 頭の位置へ補間、FOVを100度へ拡大、キャラクターモデルを非表示、カメラ回転をなぞり入力へ切り替え
- **ドローモード → 通常（確定・キャンセル・時間切れ）**: 肩越しの位置へ復帰、FOVを85度へ戻す、モデルを再表示、カメラ回転を通常操作へ戻す
- **ダッシュによるキャンセル**: ダッシュはドローモードのキャンセル手段（統合仕様書 v3.2 §4.3.7）。三人称への復帰と [ダッシュ時のFOVパルス](/spec/camera/CameraBasicPosition-dash) が重なるが、FOVは現在値（100度付近）からダッシュ時の目標値（95度）へ補間し、ダッシュ終了後に通常値（85度）へ戻る。どちらもunscaledで補間するため速度は揃う
- **ドロー中の攻撃発動**: 待機コードとBGMが一致すれば発射されるが、**カメラは変化しない**（発射はプレイヤー操作ではないため）
- **ゲームオーバー・リザルトへの遷移**: 補間を待たず通常の三人称視点へ戻す

## 他システムとの接続

- 距離・オフセット・FOVの基準値: [カメラの基準配置](/spec/camera/CameraBasicPosition)
- 回転の制限・感度・軸反転: [カメラの通常動作](/spec/camera/CameraFreeRot)
- ダッシュ時の画角変動: [カメラの基準配置（ダッシュ時）](/spec/camera/CameraBasicPosition-dash)
- ドローシステム（DrawModeSystem）: ドローモードの開始・終了の通知を受けて視点を切り替える。**なぞり入力がカメラ回転になるため、ドロー中もLook（カメラ回転）入力を有効にする必要がある**
- 入力系: ドロー中はDrawアクションマップへ切り替わるが、そこにLookを含める。画面上のカーソル（ポインタ）による選択は使わない

## 例外・禁止事項

- ドロー中にTPS・俯瞰視点へ切り替えない
- ドロー中にキャラクターモデルを表示しない
- 補間に scaled time を使わない（スロー中に切り替えや振り心地が5倍遅く見えるため）
- 攻撃の発射に合わせてカメラを動かさない
- レティクル以外の選択手段（画面上を自由に動くカーソル）を併用しない
- 数値をハードコードしない。すべて `[SerializeField]` または ScriptableObject でInspector調整可能にすること

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| 視点モデル | FPS（カメラはキャラクターの頭の位置） | 仮仕様 |
| ドロー中FOV | 水平100度（垂直換算 約68度） | 🟡仮値 |
| キャラクターモデル | 非表示 | 仮仕様 |
| なぞり入力 | カメラ回転＋画面中央のレティクル | 仮仕様 |
| 肩越しオフセット | 適用しない | 仮仕様 |
| TPS→FPSの補間時間 | 未決（短時間） | 🔴未決 |
| FPS→TPSの復帰時間 | 未決 | 🔴未決 |
| 補間・入力処理の時間軸 | unscaled time | 仮仕様 |
| ドロー中のカメラ感度 | 通常動作の設定を継承（専用倍率の要否は未決） | 🔴未決 |

## 未決事項

- 視点切り替えの補間時間（行き・戻り）
- ドロー中のカメラ感度に専用の倍率を掛けるかどうか（スロー中の精密ななぞりに通常感度が適切か）
- ドローモード終了時、キャラクターの向きをカメラの向きに合わせるか、入る前の向きに戻すか
- 移動しながらカメラを振ってなぞる操作が成立するか（移動可否そのものが仮仕様）
- ゲームパッドとマウスで、なぞりやすさの体感差をどう吸収するか
- **ドローシステム側のなぞり操作仕様（統合仕様書 v3.2 §4.3.8 の「開始＝右クリック、なぞり＝左ドラッグ」）を、レティクル方式に合わせて改訂する必要がある**
