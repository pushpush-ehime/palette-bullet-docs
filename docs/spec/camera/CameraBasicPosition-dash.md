# カメラの基準配置（ダッシュ時）

本ページでは、『Palette Bullet』においてキャラクターが「ダッシュ」状態へ移行した際の、カメラのオフセットおよび画角（FOV）の変動について定義する。
スピード感を演出しつつ、進行方向の視認性を広げることが目的である。

## 1. 変更パラメーター

通常時の基準配置（FOV・距離・オフセット）をベースとし、ダッシュ入力中は以下の値に上書き（ブレンド）される。

### 1.1 画角（FOV）の拡大
* **ダッシュ時FOV:** `95度` （※通常時から +10度などの仮値）
* **目的:** 周辺視野を広げることで、プレイヤーに疾走感（スピード感）を与える。

### 1.2 基準距離（Distance）の延長
* **ダッシュ時距離:** 通常距離 `+ XXX [cm/m]` 
* **目的:** カメラを少し後ろに引くことで、進行方向の状況（敵や障害物）をより広く見渡せるようにする。

### 1.3 オフセットの微調整
* 通常時の「右肩越し」のXYオフセットは基本的に維持する。
* ※ただし、ダッシュモーションによってキャラクターの姿勢が極端に低くなる場合は、カメラが地面に近くなりすぎないようZ軸（高さ）のみ補正値を入れる可能性がある。

## 2. 状態遷移（トランジション）仕様

カメラのFOVや距離が瞬時に切り替わると画面のガタつきや酔いの原因となるため、なめらかな補間（スムージング）を行う。

* **ダッシュ開始時（通常 → ダッシュ）:** `0.XX秒` かけて滑らかにFOVと距離を広げる。
* **ダッシュ終了時（ダッシュ → 通常）:** `0.YY秒` かけて元のFOVと距離にゆっくり戻す。
