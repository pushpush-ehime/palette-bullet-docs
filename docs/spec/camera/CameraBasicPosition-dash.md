# カメラの基準配置（ダッシュ時）

## ページ概要

ダッシュ（回避）を実行した際のカメラ画角（FOV）の変動を定義する。
通常状態の [カメラの基準配置](/spec/camera/CameraBasicPosition) からの**差分のみ**を扱う。

## 目的

- 一瞬の回避に「スッと抜けた」手応え・疾走感を与える
- 変動をFOVだけに絞り、画面のガタつき・酔い・壁際でのカメラ埋まりを起こさない

## プレイヤーから見た挙動

- ダッシュした瞬間に視界がふっと広がり、回避が終わると緩やかに元の画角へ戻る
- カメラとキャラクターの距離・位置関係は変わらない
- 視界が広がるのは一瞬だけで、広いまま維持されることはない

## 詳細仕様

ダッシュは**方向固定の一発回避**（持続は短く、クールダウンあり）であり、長押しスプリントではない。
そのためカメラ演出も「入力中は維持」ではなく、**一発のパルス**として扱う。
持続時間・クールダウンの具体的な数値はPlayer側の仕様に従い、本ページでは定義しない。

- 変動するのは**FOVのみ**。基準距離・オフセットは通常時の値を維持する
- ダッシュ時FOVは**水平95度**（16:9換算で**垂直約63度**）。通常時の水平85度から+10度
- 時間的な流れ:
  1. ダッシュ開始と同時に、短い「開き時間」でFOVを拡大する
  2. ダッシュ終了後、「戻り時間」をかけて通常時のFOVへ戻す
  3. **戻り時間 > 開き時間** とし、素早く開いて余韻を残しながら戻る形にする
- 補間は **unscaled time（実時間）** で行う。ドローモード中のスロー（0.2倍速）でも見た目の速さを変えない
- **ダッシュのクールダウン ≧ FOVの戻り時間** であることを前提とする。この条件が満たされる限り、戻り途中の再ダッシュは発生しない

## 状態別の挙動

- **ドローモード中のダッシュ**: ダッシュはドローモードのキャンセル手段（統合仕様書 v3.2 §4.3.7）。ドローモード終了・スロー解除とFOV拡大が同時に始まる。補間をunscaledにしているのはこの状況で速度が変わらないようにするため
- **ダッシュ中**: ダッシュ硬直中はドローモードへ移行できない（Player系の制約）
- **エイム中のダッシュ**: ダッシュするとエイムは解除され、通常時の画角を基準にFOVパルスが適用される（[エイム時のカメラ](/spec/camera/aim)・仮仕様）
- **障害物と干渉するとき**: 距離は変えないため競合しないが、**FOVが広がるぶん障害物判定に必要な太さは増える**。判定の太さは最大FOV基準で決める（[カメラの障害物処理](/spec/camera/collision)）

## 他システムとの接続

- 変動の基準値は [カメラの基準配置](/spec/camera/CameraBasicPosition)、回転操作は [カメラの通常動作](/spec/camera/CameraFreeRot) を参照
- Player系のダッシュ開始・終了の状態変化を受けてFOV変動を駆動する
- ドローモード（DrawModeSystem）: ダッシュによるキャンセルと同時にFOV変動が始まる

## 例外・禁止事項

- ダッシュ中にFOVを拡大したまま維持しない（長押しスプリント型の挙動にしない）
- ダッシュで基準距離・オフセットを変更しない（壁際でカメラが埋まる要因になるため）
- 補間に scaled time を使わない（スロー中に演出が5倍遅く見えるため）
- 数値をハードコードしない。すべて `[SerializeField]` または ScriptableObject でInspector調整可能にすること

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| ダッシュ時FOV | 水平95度（垂直換算 約63度） | 🟡仮値 |
| FOVの開き時間 | 未決（0.1秒未満を想定） | 🔴未決 |
| FOVの戻り時間 | 未決（開き時間より長く） | 🔴未決 |
| 基準距離の変動 | なし（通常時を維持） | 仮仕様 |
| オフセットの変動 | なし（通常時を維持） | 仮仕様 |
| 補間の時間軸 | unscaled time | 仮仕様 |

## 未決事項

- FOVの開き時間・戻り時間の数値
- ダッシュ時FOVの正式確定値（現仮値: 水平95度）
- ダッシュのモーションで姿勢が大きく変わる場合、高さ（Y軸）の補正を入れるかどうか
- ダッシュのクールダウンがFOVの戻り時間より短くなった場合、戻り途中に再ダッシュしたときの扱い
- ダッシュでエイムを解除する扱いでよいか（現状は仮仕様）
