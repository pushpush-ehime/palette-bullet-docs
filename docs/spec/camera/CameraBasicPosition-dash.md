# カメラの基準配置（ダッシュ時）

## ページ概要

ダッシュ（`ActionState = Dashing`）中のカメラ画角（FOV）の変動を定義する。
通常状態の [カメラの基準配置](/spec/camera/CameraBasicPosition) からの**差分のみ**を扱う。

ダッシュ自体の仕様（2つの内部Phase・開始条件・終了条件・スタミナ）は [Playerアクション｜ダッシュ](/spec/player/player-action-dash) を正とする。

## 目的

- ダッシュの初動に疾走感を与え、ダッシュ中はそれを継続する
- 変動をFOVだけに絞り、画面のガタつき・酔い・壁際でのカメラ埋まりを起こさない

## プレイヤーから見た挙動

- ダッシュした瞬間に視界がふっと広がる
- ダッシュ入力を押し続けて走っている間は、広がった視界が維持される
- ダッシュが終わる（入力を離す・ジャンプする・落下する・被弾する）と、緩やかに元の画角へ戻る
- カメラとキャラクターの距離・位置関係は変わらない

## 詳細仕様

Dashingは**初動高速移動Phase**（短時間の高速移動）と**Dash継続Phase**（入力を押している間の高速移動）の2段構成である（[Playerアクション｜ダッシュ](/spec/player/player-action-dash)）。カメラは内部Phaseを区別せず、**`ActionState = Dashing` の間はFOVを拡大した状態を維持する**。

- 変動するのは**FOVのみ**。基準距離・オフセットは通常時の値を維持する
- ダッシュ時FOVは**水平95度**（16:9換算で**垂直約63度**）。通常時の水平85度から+10度
- 時間的な流れ:
  1. Dashing開始と同時に、短い「開き時間」でFOVを拡大する
  2. Dashingが続いている間（初動高速移動Phase・Dash継続Phaseとも）、拡大したFOVを維持する
  3. Dashing終了と同時に、「戻り時間」をかけて通常時のFOVへ戻す
  4. **戻り時間 > 開き時間** とし、素早く開いて余韻を残しながら戻る形にする
- 初動高速移動Phaseだけで終了した場合（入力をすぐ離した一発回避的な使い方）は、結果として短いFOVパルスになる
- FOVは常に「**現在値から、その時点の状態の目標値へ補間する**」方式とする。ダッシュにクールダウンはなく、スタミナがある限り戻り補間の途中で再ダッシュできるが、その場合も現在値から拡大目標へ補間し直すだけで破綻しない
- 補間は **unscaled time（実時間）** で行う（カメラ関連ページ共通の規約。`timeScale` を変える演出が入っても見た目の速さを変えないため）

## 状態別の挙動

- **エイム中のダッシュ**: Dash開始時にAimingは解除される（[Playerアクション｜照準](/spec/player/player-action-aim) で確定）。エイムから通常カメラへの復帰補間とFOV拡大が重なるが、「現在値から目標値へ補間」の規則で処理する
- **チャージからのDashキャンセル**: `ClickCharging` / `DragCharging` からDashingへ遷移した場合も、通常のダッシュ開始と同じFOV挙動とする
- **Dashing中の先行入力**: Dashing中に保持されるCharge・Aim等の先行入力（[Playerアクション遷移](/spec/player/player-action-transitions)）はカメラに影響しない。次のActionが実際に開始された時点で、そのActionのカメラ仕様に従う
- **Jumpによる終了・接地喪失**: Dashingが終了するため、Airborne移行と同時にFOVの戻り補間を開始する
- **被弾（SmallHit / BigHit）による強制終了**: 通常FOVへの戻り補間を開始する。被弾・死亡に専用のカメラ処理が定義されている場合はそちらを優先する
- **RootState変更（Conversation / Interacting / Dead）**: Dashingが強制終了するため通常FOVへ戻す。遷移先に専用のカメラ処理がある場合はそちらを優先する
- **障害物と干渉するとき**: 距離は変えないため競合しないが、**FOVが広がるぶん障害物判定に必要な太さは増える**。判定の太さは取りうる最大FOVを基準に決める（[カメラの障害物処理](/spec/camera/collision)）

## 他システムとの接続

- 変動の基準値: [カメラの基準配置](/spec/camera/CameraBasicPosition)、回転操作: [カメラの通常動作](/spec/camera/CameraFreeRot)
- Player系: `ActionState = Dashing` の開始・終了の通知を受けてFOV変動を駆動する。ダッシュの内部Phase・終了条件は [Playerアクション｜ダッシュ](/spec/player/player-action-dash) を正とする
- 障害物処理: 判定の太さは最大FOV基準（[カメラの障害物処理](/spec/camera/collision)）

## 例外・禁止事項

- Dashing終了後までFOVを拡大したまま維持しない（拡大を維持するのは `ActionState = Dashing` の間のみ）
- ダッシュで基準距離・オフセットを変更しない（壁際でカメラが埋まる要因になるため）
- 補間に scaled time を使わない
- 数値をハードコードしない。すべて `[SerializeField]` または ScriptableObject でInspector調整可能にすること

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| ダッシュ時FOV | 水平95度（垂直換算 約63度） | 🟡仮値 |
| FOVの開き時間 | 未決（0.1秒未満を想定） | 🔴未決 |
| FOVの戻り時間 | 未決（開き時間より長く） | 🔴未決 |
| Dash継続Phase中のFOV | 拡大を維持 | 仮仕様 |
| 基準距離の変動 | なし（通常時を維持） | 仮仕様 |
| オフセットの変動 | なし（通常時を維持） | 仮仕様 |
| 補間の時間軸 | unscaled time | 仮仕様 |

## 未決事項

- FOVの開き時間・戻り時間の数値
- ダッシュ時FOVの正式確定値（現仮値: 水平95度）
- JumpやDash終了直後の再ダッシュが連続する操作で、FOVの開閉が煩わしく見えないか（実機で確認して戻り時間を調整する）
