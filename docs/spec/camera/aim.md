# エイム時のカメラ

## ページ概要

エイム（覗き込み）中のカメラ挙動を定義する。
スコープを覗いたような拡大視点にすることを狙いとし、通常状態の [カメラの基準配置](/spec/camera/CameraBasicPosition) からの**差分のみ**を扱う。

実際にスコープという装備があるわけではなく、見え方としての表現である。

## 目的

- 遠くの敵へ正確にマーカーを付けられるようにする
- 「覗き込んでいる」という手応えを画角の変化で表現する
- 拡大したときにキャラクターの体で画面が塞がらないようにする

## プレイヤーから見た挙動

- エイムすると視点が自分の頭の位置まで寄って一人称になり、画面が拡大される
- 自分のキャラクターは画面に映らなくなる
- 画面中央のレティクルで狙いを定める
- レティクルを合わせた場所へマーカーが飛ぶ
- エイムをやめると元の三人称視点に戻る

## 詳細仕様

視点はFPS（一人称）とする。カメラはキャラクターの頭の位置に置き、右肩越しのオフセットは適用しない。

- 画角は**水平FOV 60度**（16:9換算で**垂直約36度**）まで狭める。通常時の水平85度に対して**約1.6倍の拡大**にあたる
- エイム中はプレイヤーキャラクターのモデルを**非表示**にする
- カメラ回転は通常どおり有効とする。回転の制限・感度・軸反転は [カメラの通常動作](/spec/camera/CameraFreeRot) の定義を継承する
- **狙点の決定**: 画面中央のレティクルからレイを飛ばし、最初に当たった点を狙点とする。マーカーの飛翔体はキャラクター側から**その狙点へ向けて**飛ばす
  - 右肩越し配置ではカメラの正面とキャラクターの正面がずれるため、この処理を入れないと近距離で狙いが外れる
  - 何にも当たらなかった場合は、レティクル方向の十分遠い点を狙点として扱う
  - この狙点の決め方は、エイムしていない通常時のマーカー発射にも同じく適用する
- **狙点のレイに関する注意**（通常時のマーカー発射で特に重要）:
  - レイの起点は**実際のカメラ位置**とする（[カメラの障害物処理](/spec/camera/collision) で距離が縮んだ後の位置）。見えているレティクルと着弾を一致させるため
  - **プレイヤー自身のコライダーを必ず除外する。** 通常時は障害物処理で距離が縮むとオフセットXも0へ近づくため、除外しないとレイが自分の体に当たり、狙点が「自分の背中」になる
  - 狙点のレイと、カメラの障害物処理の判定は**別物**である。狙点のレイは**敵に当たる必要がある**が、障害物処理の判定は小型の敵を無視する。**同じレイヤー設定を使い回さないこと**（使い回すとマーカーが敵に付かなくなる）
- 視点の切り替えは短時間の補間で行う。補間・入力処理は **unscaled time（実時間）** で行う
- FOVは常に「現在値から、その時点の状態の目標値へ補間する」方式とする（他の状態と競合しても破綻しないようにするため）
- **エイムを発動する入力は未決**。統合仕様書 v3.2 の入力一覧にエイムは存在せず、右クリックはドローモード開始、マウスホイール押し込みはマーカー発射で埋まっているため、入力仕様側の追加・整理が必要

## 状態別の挙動

- **通常 → エイム**: 頭の位置へ補間、FOVを60度へ狭める、キャラクターモデルを非表示
- **エイム → 通常**: 肩越しの位置へ復帰、FOVを85度へ戻す、モデルを再表示
- **ダッシュ**: ダッシュするとエイムは解除される（仮仕様）。解除後は [ダッシュ時のFOVパルス](/spec/camera/CameraBasicPosition-dash) が通常時の画角を基準に適用される
- **エイム中の攻撃発動**: 待機コードとBGMが一致すれば発射されるが、**カメラは変化しない**（発射はプレイヤー操作ではないため）
- **障害物との干渉**: 一人称のため [カメラの障害物処理](/spec/camera/collision) の影響は受けない。ただし三人称への復帰補間の途中では影響を受ける（同ページの合成規則による）
- **ゲームオーバー・リザルトへの遷移**: 補間を待たず通常の三人称視点・通常FOVへ戻す

## 他システムとの接続

- 距離・オフセット・FOVの基準値: [カメラの基準配置](/spec/camera/CameraBasicPosition)
- 回転の制限・感度・軸反転: [カメラの通常動作](/spec/camera/CameraFreeRot)
- 障害物処理との合成: [カメラの障害物処理](/spec/camera/collision)
- マーカー: 本ページは狙点の決め方までを定義する。飛翔体の弾速・射程・距離制限はマーカー側の仕様に従う
- 入力系: エイムの発動入力が未定義のため、入力仕様の追加が必要

## 例外・禁止事項

- エイム中に右肩越しのオフセットを使わない（拡大時にキャラクターの体が画面を塞ぐため）
- 攻撃の発射に合わせてカメラを動かさない
- 補間に scaled time を使わない
- 狙点を決めずにキャラクターの正面へマーカーを飛ばさない（レティクルと着弾がずれるため）
- 数値をハードコードしない。すべて `[SerializeField]` または ScriptableObject でInspector調整可能にすること

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| 視点モデル | FPS（カメラはキャラクターの頭の位置） | 仮仕様 |
| エイム時FOV | 水平60度（垂直換算 約36度・通常比 約1.6倍） | 🟡仮値 |
| キャラクターモデル | 非表示 | 仮仕様 |
| 肩越しオフセット | 適用しない | 仮仕様 |
| 狙点の決定 | 画面中央のレイの命中点 | 仮仕様 |
| エイムの発動入力 | 未決 | 🔴未決 |
| 切り替えの補間時間 | 未決 | 🔴未決 |
| エイム中の感度倍率 | 未決 | 🔴未決 |
| 補間・入力処理の時間軸 | unscaled time | 仮仕様 |

## 未決事項

- **エイムを発動する入力**（v3.2の入力一覧にエイムがなく、右クリックとホイール押し込みは他の操作で埋まっている）
- 視点切り替えの補間時間（行き・戻り）
- エイム中のカメラ感度に倍率を掛けるかどうか（拡大時は感度を落とすのが一般的）
- エイム中に移動できるか、移動速度を落とすか
- ドローモード中にエイムできるようにするか（現状は排他の仮仕様）
- マーカーを付ける以外にエイムを使う場面があるか
- エイム時FOVの正式確定値（現仮値: 水平60度）
