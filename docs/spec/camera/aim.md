# エイム時のカメラ

## ページ概要

エイム（`AimState = Aiming`）中のカメラ挙動を定義する。
通常状態の [カメラの基準配置](/spec/camera/CameraBasicPosition) からの**差分のみ**を扱う。

Aimingの開始・終了条件、入力方式、Playerの向き、移動速度は [Playerアクション｜照準](/spec/player/player-action-aim) を正とする。本ページは、その要求を満たすカメラ側の実装仕様（位置・画角・補間・狙点のレイ）を定義する。

## 目的

- 遠くの敵へ正確にマーカーを付けられるようにする
- 「覗き込んでいる」という手応えを、カメラの寄りと画角の変化で表現する
- 通常カメラとの行き来を、どの解除経路でも破綻なく行う

## プレイヤーから見た挙動

- エイムすると、カメラがキャラクターへ寄って肩越しの覗き込み視点になり、画面がやや拡大される
- キャラクターは画面に映ったままで、一人称にはならない
- キャラクターはカメラの向いている方向へ向き直る
- 画面中央のレティクルで狙いを定め、レティクルを合わせた場所へマーカーが飛ぶ
- エイム中もカメラは自由に回せる。感度はエイム用に調整される
- エイムをやめると（またはダッシュ・被弾・落下などで解除されると）元のカメラへ戻る

## 詳細仕様

視点は**TPSのまま維持**し、カメラをキャラクターへ近づけた**肩越しズーム**とする（[Playerアクション｜照準](/spec/player/player-action-aim) の「肩越しに近いカメラ位置へ変更する」に従う）。FPS化・キャラクターモデルの非表示は行わない。

- **カメラ位置**: 通常時の注視点オフセット・基準距離から、エイム用の位置（`AimCameraOffset`）へ補間する
- **画角**: FOVをエイム用の値（`AimFOV`）へ狭め、拡大感を出す。旧仮値の水平60度はFPS視点前提の値のため、肩越しズームでの適正値は改めて調整する
- **感度**: Look感度に `AimLookSensitivityMultiplier` を適用する
- **補間**: 通常⇔エイムの切り替えは `AimCameraTransitionDuration` で補間する。位置・FOVとも常に「現在値から、その時点の状態の目標値へ補間する」方式とし、他の状態と競合しても破綻しないようにする
- 補間・入力処理は **unscaled time（実時間）** で行う
- パラメータ名は [Playerアクション｜照準](/spec/player/player-action-aim) のパラメータ表と共通とし、値の管理もPlayer側の表を正とする

### 狙点の決定

- 画面中央のレティクルからレイを飛ばし、最初に当たった点を**狙点**とする。マーカーは武器の発射位置から**その狙点へ向けて**発射する（発射位置・発射タイミングは [Playerアクション｜マーカー](/spec/player/player-action-marker) を正とする）
- Aiming中はPlayerがカメラの水平方向へ向き直るため正面のずれは小さいが、カメラと武器の位置は常にずれているため、この処理を入れないと近距離で狙いが外れる
- 何にも当たらなかった場合は、レティクル方向の十分遠い点を狙点として扱う

### 狙点のレイに関する注意

- レイの起点は**実際のカメラ位置**とする（[カメラの障害物処理](/spec/camera/collision) で距離が縮んだ後の位置）。見えているレティクルと着弾を一致させるため
- **プレイヤー自身のコライダーを必ず除外する。** 除外しないとレイが自分の体に当たり、狙点が「自分の背中」になる
- 狙点のレイと、カメラの障害物処理の判定は**別物**である。狙点のレイは**敵に当たる必要がある**が、障害物処理の判定は小型の敵を無視する。**同じレイヤー設定を使い回さないこと**（使い回すとマーカーが敵に付かなくなる）

## 状態別の挙動

Aimingの開始・終了の成立条件そのものは [Playerアクション｜照準](/spec/player/player-action-aim) を正とし、カメラは通知を受けて目標値を差し替える。

- **Normal → Aiming**: エイム用の位置・FOVへ補間し、エイム用感度を適用する
- **Aiming → Normal**: 通常時の位置・FOV・感度へ補間して戻す。解除経路（Aim終了操作・Dashing開始・Parrying開始・SmallHit / BigHit・Airborne移行・RootState変更）にかかわらず同じ復帰処理を行う。ただし被弾・死亡など専用のカメラ処理が定義されている場合はそちらを優先する
- **Dashing開始**: Dash開始時にAimingは解除される（Player仕様で確定）。通常カメラへの復帰補間と [ダッシュ時のFOV変動](/spec/camera/CameraBasicPosition-dash) が重なるが、「現在値から目標値へ補間」の規則で処理する
- **MarkerFiring / ClickCharging / DragChargingとの同時成立**: これらのActionが開始・終了してもAimingは継続するため、カメラはエイム状態を維持する
- **エイム中の攻撃発動**: 攻撃（パレットブレットの発射）が発生してもカメラは変化しない
- **障害物との干渉**: エイム中もTPSのため [カメラの障害物処理](/spec/camera/collision) は有効。エイム位置はキャラクターに近いため、実際に干渉する場面は限られる
- **ゲームオーバー・リザルトへの遷移**: 補間を待たず通常カメラへ即座に戻す

## 他システムとの接続

- Aimingの開始・終了条件・入力方式・Playerの向き・移動速度: [Playerアクション｜照準](/spec/player/player-action-aim)（入力の物理割当は [Player入力と操作](/spec/player/input-and-controls)。デフォルトは右クリック・照準長押し方式）
- マーカーの発射位置・発射方向・発射タイミング: [Playerアクション｜マーカー](/spec/player/player-action-marker)。本ページは狙点の決め方までを定義する
- 位置・FOVの基準値: [カメラの基準配置](/spec/camera/CameraBasicPosition)
- 回転の制限・軸反転: [カメラの通常動作](/spec/camera/CameraFreeRot)
- 障害物処理との関係: [カメラの障害物処理](/spec/camera/collision)

## 例外・禁止事項

- エイム中にFPS視点へ切り替えない・キャラクターモデルを非表示にしない（旧仕様の挙動。現仕様は肩越しズーム）
- 攻撃の発射に合わせてカメラを動かさない
- 補間に scaled time を使わない
- 狙点を決めずにキャラクターの正面へマーカーを飛ばさない（レティクルと着弾がずれるため）
- 数値をハードコードしない。すべて `[SerializeField]` または ScriptableObject でInspector調整可能にすること

## パラメータ

パラメータ名・値の管理は [Playerアクション｜照準](/spec/player/player-action-aim) のパラメータ表と共通。

| パラメータ | 値 | 状態 |
|---|---|---|
| 視点モデル | TPSのまま肩越しズーム（FPS化しない） | 仮仕様 |
| `AimFOV` | 未定（旧仮値の水平60度はFPS前提のため再調整） | 🔴未決 |
| `AimCameraOffset` | 未定 | 🔴未決 |
| `AimCameraTransitionDuration` | 未定 | 🔴未決 |
| `AimLookSensitivityMultiplier` | 未定 | 🔴未決 |
| 狙点の決定 | 画面中央のレイの命中点 | 仮仕様 |
| 補間・入力処理の時間軸 | unscaled time | 仮仕様 |

## 未決事項

- `AimFOV`・`AimCameraOffset`・`AimCameraTransitionDuration`・`AimLookSensitivityMultiplier` の数値（Player側パラメータと共通）
- 肩越しズームでの拡大率
