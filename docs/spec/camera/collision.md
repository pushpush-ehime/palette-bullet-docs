# カメラの障害物処理

## ページ概要

カメラと地形・障害物が干渉した場合の処理を定義する。
壁越しにキャラクターが見えなくなること、カメラが壁や地面にめり込むことを防ぐ。

本処理は [カメラの基準配置](/spec/camera/CameraBasicPosition) の基準距離を上限として、距離を縮める方向にのみ働く。

## 目的

- 壁や地形に遮られてキャラクターが見えなくなるのを防ぐ
- カメラが壁・地面を突き抜けて内部が見えてしまうのを防ぐ
- 狭い通路や壁際でも操作を続けられるようにする
- カメラが暴れて画面がガタつかないようにする

## プレイヤーから見た挙動

- 壁とキャラクターの間にカメラが入りそうになると、カメラが自動的に手前へ寄って視界が保たれる
- 狭い通路や壁際でも、カメラが壁を突き抜けて外の景色が見えることはない
- カメラが近づきすぎるときは、自分のキャラクターが薄くなって消え、前方が見えたままになる
- 障害物から離れると、カメラは元の距離へなめらかに戻る
- 柱や手すりの前を走ってもカメラが激しく前後しない

## 詳細仕様

### 基本の考え方

- 毎フレーム**目標距離**を求め、現在の距離をそこへ寄せる方式とする（状態として持たない）
- 目標距離は、判定の結果を **最小距離 〜 基準距離** の範囲に収めた値とする
- 判定は注視点からカメラ位置へ向けて飛ばす。注視点の定義（オフセット適用済み）は [カメラの基準配置](/spec/camera/CameraBasicPosition) に従う

### 判定の方法

- 判定には**太さを持たせる**（球状の判定を使う）。線だけの判定では、カメラの手前の描画面（near平面）が壁を貫いてしまうため
- **判定の太さは near clip から逆算する。** near平面の外接半径以上が必要で、**取りうる最大FOV（現状はダッシュ時の水平95度）を基準に決める**
  - near clip 0.1 の場合、水平95度で約0.16m。ここに余裕を足した値を使う
  - 通常時のFOVで調整すると、ダッシュ中だけ壁が貫通する。Dashing中は拡大FOVが維持されるため（[カメラの基準配置（ダッシュ時）](/spec/camera/CameraBasicPosition-dash)）、これは一瞬の問題ではない
- カメラ位置は「判定の起点 + 方向 × 判定が進めた距離」で求める。**衝突点と法線から逆算しない**（壁の角や柱の稜線で法線が不連続に変わり、カメラが跳ねるため）
- **判定の起点が既に障害物と重なっている場合**（壁に体を密着させたときなど）、球状の判定はヒットを返さないことがある。この場合は目標距離を最小距離まで縮めるフォールバックを必ず用意する。フォールバックがないとカメラが壁の外へ飛び出す

### 判定の対象

- 対象は**地形・静的な障害物のみ**とする
- 次は対象に**含めない**:
  - プレイヤー自身のコライダー（注視点はキャラクターの体の近くにあるため、含めると常に距離が0になる）
  - トリガーコライダー（エリア判定・BGMトリガーなどで見えない壁に寄ってしまう）
  - 小型の敵・シャオンダマ・エフェクト（視界が絶えずガタつくため）
- ただし**ラジクジラのような大型の敵は例外**とし、カメラ判定用の簡易コライダーを持たせて対象に含める。含めないと巨大な敵の体内にカメラが入り、数秒間何も見えなくなる
- 柱・柵・手すりなど断面の小さい地形は、カメラ判定から除外するレイヤーへ置く。一瞬キャラクターが隠れるほうが、カメラが往復して暴れるより体験がよい

### 距離の変化のさせ方

- **寄る方向は速い、戻る方向は遅い**。ただし寄る側も瞬間移動させず、**上限速度を設けた高速追従**とする
  - 瞬間的に寄せると、弾を避けている最中に視界が一気に狭まり、避けようのない被弾につながる
  - 例外として、カメラが実際に障害物へめり込んでいる場合のみ即座に補正してよい
- 戻る方向には**短いディレイ（ヒステリシス）**を設ける。柱や手すりを横切るたびに「寄る→戻る」を繰り返して画面が暴れるのを防ぐ
- 速度は「補間にかける時間」ではなく **m/s（速度）** で定義する。時間で定義すると、0.3m戻るときと4m戻るときが同じ時間になり、小さな復帰がもたつく
- 補間は **unscaled time（実時間）** で行う。現状のTPS状態では `timeScale` は1だが、将来スロー中にTPSを使う状態が増えても挙動が変わらないようにするため

### 近づきすぎたときのキャラクター表示

- 距離が縮むほど、プレイヤーキャラクターを**半透明化し、最終的に非表示**にする
  - 距離だけ縮めてモデルをそのまま表示すると、キャラクターの体で画面が埋まり、近接面を貫通して体の内部が見える
- あわせて、距離が縮むほど**オフセットX（右方向）も0へ縮める**。肩越しのまま寄るとキャラクターが画面の右半分を占領し、右から来る邪音玉が見えなくなる
- 半透明化の開始距離・完全非表示になる距離はInspectorで調整可能にする

### エイム（肩越しズーム）との合成

- 本処理は**状態にかかわらず常に計算する**。「エイム中は無効にする」という分岐は設けない
- 目標距離の上限には、**その時点の状態が定める目標のカメラ距離**を使う（通常時は基準距離、エイム中はエイム用の距離。[エイム時のカメラ](/spec/camera/aim)）
- 通常とエイムの切り替え補間の途中でも判定が効くため、壁際でエイムを開始・解除しても壁を貫通しない

### リセット

- ゲーム状態のリセット時は、補間を待たず現在距離を目標距離に即座に一致させる

## 状態別の挙動

- **通常時**: 有効
- **ダッシュ中**: 有効。ダッシュでは距離を変えないため距離の競合はないが、**Dashing中は拡大FOVが維持される**ため、判定の太さは最大FOV基準で決める
- **エイム中**: 有効。カメラがキャラクターへ寄っており障害物と干渉する場面は限られるが、処理は動き続ける（[エイム時のカメラ](/spec/camera/aim)）
- **チャージ中（`ClickCharging` / `DragCharging`）**: カメラは通常時と同じため、通常どおり有効
- **通常とエイムの切り替え補間中**: 有効。その時点の目標位置に対して距離の縮めを適用する
- **見下ろしているとき**: [カメラの基準配置](/spec/camera/CameraBasicPosition) のピッチ連動で地面に接触しない配置が先に作られている前提で、残りを本処理が拾う

## 他システムとの接続

- 注視点の定義・基準距離・near clip: [カメラの基準配置](/spec/camera/CameraBasicPosition)
- **マーカーの狙点**: 狙点を決めるレイと本処理の判定は**別物**である。狙点のレイは敵に当たる必要があり、本処理の判定は小型の敵を無視する。同じレイヤー設定を使い回さないこと（詳細は [エイム時のカメラ](/spec/camera/aim)）
- ステージ: 判定対象のコライダーとレイヤーの用意はステージ側で行う。カメラ側からの要求は「地形・静的障害物のレイヤー」と「カメラ判定から除外する薄い地形のレイヤー」の2種類
- 敵: 大型の敵にはカメラ判定用の簡易コライダーが必要

## 例外・禁止事項

- プレイヤー自身のコライダーとトリガーコライダーを判定対象に含めない
- 小型の敵・シャオンダマ・エフェクトを理由にカメラを寄せない（視界が絶えずガタつくため）
- 障害物から離れるときにカメラを瞬間移動させない
- 基準距離より遠くへカメラを離さない
- 「エイム中は処理を止める」という分岐を作らない（切り替え補間中に壁を貫通するため）
- 判定の太さを通常時のFOVだけを見て決めない（広角時に貫通するため）
- 数値をハードコードしない。すべて `[SerializeField]` または ScriptableObject でInspector調整可能にすること

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| 判定方法 | 注視点からカメラ位置への球状の判定 | 仮仕様 |
| 判定の太さ（半径） | near平面の外接半径以上（near clip 0.1・最大FOV95度で約0.16m）＋余裕 | 🟡仮値 |
| 最小距離 | 未決（基準距離の確定後に決める） | 🔴未決 |
| 寄る速度 | 上限速度あり（値は未決）。めり込み時のみ即座 | 🔴未決 |
| 戻る速度 | 寄る速度より遅い（値は未決） | 🔴未決 |
| 戻り開始のディレイ | 未決 | 🔴未決 |
| キャラクター半透明化の開始距離 | 未決 | 🔴未決 |
| キャラクター非表示になる距離 | 未決 | 🔴未決 |
| オフセットXの縮小 | 距離の縮小に連動して0へ | 仮仕様 |
| 判定の対象 | 地形・静的障害物・大型敵の簡易コライダー | 仮仕様 |
| エイムとの合成 | 常時計算し、状態が定める目標距離を上限に適用 | 仮仕様 |
| 補間の時間軸 | unscaled time | 仮仕様 |

## 未決事項

- 判定の太さ・最小距離・寄る速度・戻る速度・戻り開始ディレイの数値
  - **決定順序**: [カメラの基準配置](/spec/camera/CameraBasicPosition) の基準距離 → 最小距離 → その他。基準距離が未決のうちは確定できない
- キャラクターの半透明化の実現方法（ディザ透過用のシェーダが必要になるため、デザイン班との調整が要る）
- 半透明化を開始する距離・完全に消える距離
- 動く障害物（可動する地形など）を判定対象に含めるか
- カメラ判定用レイヤーの命名と、コライダー整備のステージ班との分担
