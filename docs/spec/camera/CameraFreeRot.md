# カメラの通常動作

## ページ概要

プレイヤー入力によるカメラの回転（ヨー・ピッチ）と、その角度制限・ユーザー設定を定義する。
カメラの位置・距離・画角は [カメラの基準配置](/spec/camera/CameraBasicPosition) を正とし、本ページでは扱わない。

## 目的

- 状況把握・索敵のために、プレイヤーが任意の方向を見られるようにする
- 画面が反転する・地面にめり込むといった破綻を角度制限で防ぐ
- 感度と反転をプレイヤー側で調整可能にし、操作の好みの差を吸収する

## プレイヤーから見た挙動

- 右スティック／マウス移動でカメラを自由に回せる
- カメラを回しただけではキャラクターの向きは変わらない
- 移動入力を入れると、キャラクターはカメラを基準にした移動方向へ向き直って走る
- 真上・真下までは見えない
- 感度と上下左右の反転はオプション画面で変更できる

## 詳細仕様

プレイヤーキャラクターを注視点（Pivot）とし、一定の距離を保った状態で球面を這うようにカメラが旋回する。

### 操作割り当て

| デバイス | 入力 | アクション |
|---|---|---|
| ゲームパッド | 右スティック（X軸／Y軸） | カメラの左右回転（ヨー）／上下回転（ピッチ） |
| マウス | マウス移動（X軸／Y軸） | カメラの左右回転（ヨー）／上下回転（ピッチ） |

### 左右回転（ヨー / Yaw）

- キャラクターの周囲を水平方向に旋回する
- 制限なし（0〜360度シームレスにループ回転可能）
- キャラクターの向きとの連動:
  - カメラ操作のみではキャラクターの向きは変わらない
  - 移動入力があるとき、キャラクターは**カメラを基準にした移動方向**へ向き直る（カメラの正面方向ではない）。例として後ろ方向の入力では、キャラクターはカメラ側を向いて手前へ走る
  - 向き直りは瞬時ではなく補間で行う

### 上下回転（ピッチ / Pitch）

- キャラクターを中心に垂直方向に旋回する
- カメラの反転（宙返り）を防ぎ、真上・真下が見えないようにするため、角度制限を設ける
  - 見上げ限界（上限角度）: `+70度`（仮値。真上までは見えない程度）
  - 見下ろし限界（下限角度）: `-45度`（仮値。真下は見えない程度）
- **地面へのめり込みは、この角度制限だけでは防げない。** 見下ろし限界の-45度でもカメラは注視点より大きく下がるため、[カメラの基準配置](/spec/camera/CameraBasicPosition) のピッチ連動で基準距離を短くして予防し、残りを [カメラの障害物処理](/spec/camera/collision) が拾う

### 位置・距離・画角

本ページでは定義しない。注視点のオフセット・基準距離・FOVは [カメラの基準配置](/spec/camera/CameraBasicPosition) を参照する。

### ユーザー設定（オプション）

プレイヤーの好みに合わせ、オプション画面で以下を変更可能とする。

| 設定項目 | 説明 |
|---|---|
| カメラ感度（X軸／Y軸） | スティック・マウス入力に対するカメラの回転速度。X/Y独立して設定可能 |
| X軸（左右）の反転 | ONにすると、右入力でカメラが左へ、左入力でカメラが右へ回転する |
| Y軸（上下）の反転 | ONにすると、上入力でカメラが下へ、下入力でカメラが上へ回転する |

## 状態別の挙動

- **ダッシュ中**: 回転操作は通常どおり有効。FOVのみ変動する（[カメラの基準配置（ダッシュ時）](/spec/camera/CameraBasicPosition-dash)）
- **ドローモード中**: 視点がFPSへ切り替わり、カメラ回転はなぞり入力を兼ねる（画面中央のレティクルで玉をなぞる）。回転の制限・感度・軸反転は本ページの定義を継承する。詳細は [ドローモード時のカメラ](/spec/camera/draw-mode)
- **エイム（覗き込み）中**: 視点がFPSへ切り替わり画角が狭まるが、回転操作は本ページの定義どおり有効。詳細は [エイム時のカメラ](/spec/camera/aim)
- **障害物と干渉するとき**: 回転は通常どおりで、距離のみ縮む。詳細は [カメラの障害物処理](/spec/camera/collision)

## 他システムとの接続

- 位置・距離・画角の基準値: [カメラの基準配置](/spec/camera/CameraBasicPosition)
- Player系: 移動入力の前後左右は、このカメラの向きを基準に解釈される（カメラ基準移動）
- 入力系: GameplayアクションマップのLookを唯一の回転入力源とする
- 設定UI: 感度・反転の設定値の保持・保存はUI／設定システム側で扱う

## 例外・禁止事項

- カメラ操作だけでキャラクターの向きを変えない
- 攻撃を理由にキャラクターをカメラ正面へ向き直らせない。攻撃はBGMと待機コードの照合による自動発動であり、プレイヤーが攻撃を撃つ操作は存在しない
- エイム（覗き込み）中もキャラクターをカメラ正面へ向き直らせない。狙いは画面中央のレティクルで決まるため、体の向きを合わせる必要がない（[エイム時のカメラ](/spec/camera/aim)）
- ピッチの角度制限を撤廃しない（カメラ反転・地面へのめり込みを防ぐため）
- 数値をハードコードしない。すべて `[SerializeField]` または ScriptableObject でInspector調整可能にすること

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| 見上げ限界（ピッチ上限） | +70度 | 🟡仮値 |
| 見下ろし限界（ピッチ下限） | -45度 | 🟡仮値 |
| ヨーの制限 | なし（360度ループ） | 仮仕様 |
| カメラ感度（X／Y） | デフォルト50（0〜100・X/Y独立） | 🟡仮値 |
| X軸の反転 | デフォルト OFF | 仮仕様 |
| Y軸の反転 | デフォルト OFF | 仮仕様 |
| キャラクターの向き直り速度 | 未決 | 🔴未決 |

## 未決事項

- ピッチ制限の正式確定値（現仮値 +70度／-45度）
- 感度の目盛り（0〜100）を実際の回転速度へ換算する式・上下限
- キャラクターの向き直り速度（補間の速さ）
- 感度・反転設定の保存方法と、設定UIの所在

ドローモード中・エイム中の感度倍率は、それぞれ [ドローモード時のカメラ](/spec/camera/draw-mode)・[エイム時のカメラ](/spec/camera/aim) 側で管理する。
