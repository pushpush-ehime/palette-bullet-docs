# カメラの通常動作

## ページ概要

プレイヤー入力によるカメラの回転（ヨー・ピッチ）と、その角度制限・ユーザー設定を定義する。
カメラの位置・距離・画角は [カメラの基準配置](/spec/camera/CameraBasicPosition) を正とし、本ページでは扱わない。

## 目的

- 状況把握・索敵のために、プレイヤーが任意の方向を見られるようにする
- 画面が反転する・地面にめり込むといった破綻を角度制限で防ぐ
- 感度と反転をプレイヤー側で調整可能にし、操作の好みの差を吸収する

## プレイヤーから見た挙動

- マウス移動（ゲームパッド対応時は右スティック）でカメラを自由に回せる
- カメラを回しただけではキャラクターの向きは変わらない（エイム中を除く）
- 移動入力を入れると、キャラクターはカメラを基準にした移動方向へ向き直って走る
- エイム中は、キャラクターがカメラの向いている方向へ向き直る
- 真上・真下までは見えない
- 感度と上下左右の反転はオプション画面で変更できる

## 詳細仕様

プレイヤーキャラクターを注視点（Pivot）とし、一定の距離を保った状態で球面を這うようにカメラが旋回する。

### 操作割り当て

回転入力は入力アクション `Look` を唯一の入力源とする。物理入力の割当は [Player入力と操作](/spec/player/input-and-controls) を正とする。

| デバイス | 入力 | アクション |
|---|---|---|
| マウス | マウス移動（X軸／Y軸） | カメラの左右回転（ヨー）／上下回転（ピッチ） |
| ゲームパッド | 右スティック（X軸／Y軸） | カメラの左右回転（ヨー）／上下回転（ピッチ） |

ゲームパッド対応自体が未確定のため（[Player入力と操作](/spec/player/input-and-controls)）、ゲームパッド行は対応が決まった場合の割当とする。

### 左右回転（ヨー / Yaw）

- キャラクターの周囲を水平方向に旋回する
- 制限なし（0〜360度シームレスにループ回転可能）
- キャラクターの向きとの連動:
  - 通常時（`AimState = Normal`）、カメラ操作のみではキャラクターの向きは変わらない
  - 移動入力があるとき、キャラクターは**カメラを基準にした移動方向**へ向き直る（カメラの正面方向ではない）。例として後ろ方向の入力では、キャラクターはカメラ側を向いて手前へ走る
  - **エイム中（`AimState = Aiming`）は例外**として、キャラクターの正面はカメラの水平方向へ追従する。この向き追従の仕様は [Playerアクション｜照準](/spec/player/player-action-aim) を正とする
  - 向き直りは瞬時ではなく補間で行う

### 上下回転（ピッチ / Pitch）

- キャラクターを中心に垂直方向に旋回する
- カメラの反転（宙返り）を防ぎ、真上・真下が見えないようにするため、角度制限を設ける
  - 見上げ限界（上限角度）: `+70度`（仮値。真上までは見えない程度）
  - 見下ろし限界（下限角度）: `-45度`（仮値。真下は見えない程度）
- **地面へのめり込みは、この角度制限だけでは防げない。** 見下ろし限界の-45度でもカメラは注視点より大きく下がるため、[カメラの基準配置](/spec/camera/CameraBasicPosition) のピッチ連動で基準距離を短くして予防し、残りを [カメラの障害物処理](/spec/camera/collision) が拾う

### 位置・距離・画角

本ページでは定義しない。注視点のオフセット・基準距離・FOVは [カメラの基準配置](/spec/camera/CameraBasicPosition) を参照する。

### ユーザー設定（オプション）

プレイヤーの好みに合わせ、オプション画面で以下を変更可能とする。

| 設定項目 | 説明 |
|---|---|
| カメラ感度（X軸／Y軸） | スティック・マウス入力に対するカメラの回転速度。X/Y独立して設定可能 |
| X軸（左右）の反転 | ONにすると、右入力でカメラが左へ、左入力でカメラが右へ回転する |
| Y軸（上下）の反転 | ONにすると、上入力でカメラが下へ、下入力でカメラが上へ回転する |

エイム中はこの感度に `AimLookSensitivityMultiplier`（[Playerアクション｜照準](/spec/player/player-action-aim)）を乗算する。軸反転の設定は全状態で共通に適用する。

## 状態別の挙動

- **ダッシュ中（`ActionState = Dashing`）**: 回転操作は通常どおり有効。FOVのみ変動する（[カメラの基準配置（ダッシュ時）](/spec/camera/CameraBasicPosition-dash)）
- **エイム中（`AimState = Aiming`）**: カメラがキャラクターへ寄る肩越しズームになるが、回転操作は本ページの定義どおり有効。感度にエイム用の倍率を適用し、キャラクターの向きがカメラの水平方向へ追従する。詳細は [エイム時のカメラ](/spec/camera/aim)
- **チャージ中（`ActionState = ClickCharging / DragCharging`）**: カメラは通常どおり。DragChargingのシャオンダマ選択は、画面中央のレティクルをカメラ回転で動かして行う。チャージの仕様は [Playerアクション｜チャージ](/spec/player/player-action-charge) を正とする
- **障害物と干渉するとき**: 回転は通常どおりで、距離のみ縮む。詳細は [カメラの障害物処理](/spec/camera/collision)

## 他システムとの接続

- 位置・距離・画角の基準値: [カメラの基準配置](/spec/camera/CameraBasicPosition)
- Player系: 移動入力の前後左右は、このカメラの向きを基準に解釈される（カメラ基準移動。[Player基本移動](/spec/player/basic-movement) を正とする）
- エイム中のPlayerの向き追従・感度倍率: [Playerアクション｜照準](/spec/player/player-action-aim)
- 入力系: 入力アクション `Look` を唯一の回転入力源とする。物理割当は [Player入力と操作](/spec/player/input-and-controls)
- 設定UI: 感度・反転の設定値の保持・保存はUI／設定システム側で扱う

## 例外・禁止事項

- 通常時（`AimState = Normal`）、カメラ操作だけでキャラクターの向きを変えない（エイム中の向き追従は [Playerアクション｜照準](/spec/player/player-action-aim) の定義に従う）
- 攻撃（パレットブレットの発射）を理由にキャラクターをカメラ正面へ向き直らせない。発射はAttackEvent側の自動処理であり、発射の瞬間にプレイヤーの操作は存在しない
- ピッチの角度制限を撤廃しない（カメラ反転・地面へのめり込みを防ぐため）
- 数値をハードコードしない。すべて `[SerializeField]` または ScriptableObject でInspector調整可能にすること

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| 見上げ限界（ピッチ上限） | +70度 | 🟡仮値 |
| 見下ろし限界（ピッチ下限） | -45度 | 🟡仮値 |
| ヨーの制限 | なし（360度ループ） | 仮仕様 |
| カメラ感度（X／Y） | デフォルト50（0〜100・X/Y独立） | 🟡仮値 |
| X軸の反転 | デフォルト OFF | 仮仕様 |
| Y軸の反転 | デフォルト OFF | 仮仕様 |
| キャラクターの向き直り速度 | 未決 | 🔴未決 |

エイム中の感度倍率（`AimLookSensitivityMultiplier`）・エイム中の向き追従の回転速度（`AimRotationSpeed`）は [Playerアクション｜照準](/spec/player/player-action-aim) 側で管理する。

## 未決事項

- ピッチ制限の正式確定値（現仮値 +70度／-45度）
- 感度の目盛り（0〜100）を実際の回転速度へ換算する式・上下限
- キャラクターの向き直り速度（補間の速さ）
- 感度・反転設定の保存方法と、設定UIの所在
