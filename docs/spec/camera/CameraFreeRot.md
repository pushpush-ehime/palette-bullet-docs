# TPS用フリーカメラ

## 1. 概要
プレイヤーキャラクターの後方にカメラを配置するTPS視点を基本とし、プレイヤーの入力（右スティック／マウス）によってカメラを任意の方向へ自由に回転させることができる。

## 2. 操作割り当て

| デバイス | 入力 | アクション |
| :--- | :--- | :--- |
| **ゲームパッド** | 右スティック (X軸 / Y軸) | カメラの左右回転（ヨー） / 上下回転（ピッチ） |
| **マウス** | マウス移動 (X軸 / Y軸) | カメラの左右回転（ヨー） / 上下回転（ピッチ） |

## 3. 基本挙動仕様

プレイヤーキャラクターを注視点（Pivot）とし、一定の距離を保った状態で球面を這うようにカメラが旋回する。

### 3.1 左右回転（ヨー / Yaw）
* **挙動:** キャラクターの周囲を水平方向に旋回する。
* **制限:** なし（0〜360度シームレスにループ回転可能）。
* **キャラクターの向きとの連動:**
  * フリーカメラ操作のみではキャラクターの向きは変わらない。
  * 移動入力（左スティック/WASD）、またはエイム（攻撃）アクションを行った際に、キャラクターがカメラの正面方向へ向き直る。

### 3.2 上下回転（ピッチ / Pitch）
* **挙動:** キャラクターを中心に垂直方向に旋回する。
* **制限:** カメラが反転する（宙返りする）ことを防ぐため、および地面への極端なめり込みを防ぐため、角度制限を設ける。
  * **見上げ限界（上限角度）:** `+70度` （※仮設定値。真上までは見えない程度）
  * **見下ろし限界（下限角度）:** `-45度` （※仮設定値。真下は見えない程度）

### 3.3 カメラオフセットと基準距離
TPS特有の「プレイヤーキャラクターが画面中央を塞がない」ためのオフセット（位置ずらし）を設定する。

* **基準距離:** 注視点からカメラまでの基本距離は `X [m]` とする。
* **オフセット設定:** 注視点をキャラクターの「頭の少し上」かつ「右肩越し（右側へ少しずらす）」に配置する。
  * `X, Y, Z = (Right: XX, Up: XX, Forward: XX)` 

## 4. ユーザー設定（オプション設定）

プレイヤーの好みに合わせ、オプション画面で以下の項目を変更可能とする。

| 設定項目 | 説明 | デフォルト値 |
| :--- | :--- | :--- |
| **カメラ感度（X軸 / Y軸）** | スティック・マウス入力に対するカメラの回転速度。X/Y独立して設定可能。 | 50 (0~100) |
| **X軸（左右）の反転** | ONにすると、右入力でカメラが左へ、左入力でカメラが右へ回転する。 | OFF |
| **Y軸（上下）の反転** | ONにすると、上入力でカメラが下へ、下入力でカメラが上へ回転する。 | OFF |
