# 重複チャージ・蓄積仕様

## 目的
例えば、

要求

C
C
G

に対して、

1個目のC
→ C①

2個目のC
→ C②

3個目以降のC
→ C①へ重複

です。

そして、

C① × 8
C② × 1
G × 1

ならAttackEvent発火時には、

C × 9
G × 1

が全部発射されます。

ここにはゲームデザイン上の意味も書けます。

1つの音へ大量チャージすると強い一撃を作れるが、後続AttackEventへ使用するシャオンダマが不足し、コンボを維持しにくくなる。

これは重要なトレードオフです。
