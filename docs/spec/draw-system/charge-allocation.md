# チャージ先・スロット割り当て仕様

## 目的
これはチャージシステムの中で一番重要なページになると思います。

プレイヤーがシャオンダマを選んだあと、どこへ入るのかを決めます。
例えば、

AttackEvent 1
C / E / G

AttackEvent 2
A / C / E

AttackEvent 3
G / B / D

が表示されていてCを選んだら、

AttackEvent 1 の未チャージC
↓
最優先

次のC
↓
AttackEvent 2 の未チャージC

というルールを書きます。
