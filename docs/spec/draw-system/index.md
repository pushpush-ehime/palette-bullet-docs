# チャージシステム

ここが今回のゲームプレイの中心です。

書く内容は、

- 世界のシャオンダマをどう選択するか
- クリックによる選択
- なぞりによる選択
- コードとアルペジオでの操作方法
- 表示しておくAttackEventの最大数
- 選択した音をどのAttackEventへ入れるか
- 未チャージスロット優先
- 複数AttackEvent間の優先順位
- 同じ音の重複チャージ
- 1スロットに複数弾を蓄積できること
- 不要な音を選択した場合のミス
- なぞりによる強化
- 難易度が高い場合の操作補助

を担当させます。

## チャージの流れ
```text
AttackEvent予告
↓
必要音を確認
↓
世界のシャオンダマを選択
↓
対応スロットへ自動チャージ
↓
AttackEvent発火
↓
チャージした弾を発射
```
