# Playerアクション|マーカー
## 目的
このページではPlayerアクションの一つであるマーカー発射について解説していきます。

マーカー自体の機能は別のオブジェクトなので、そちらに記載します。
## マーカーとは
本ゲームにおけるマーカーは、Playerの攻撃｜パレットブレットがどこに飛んでいくかを、任意で決めるための道具です。

Playerはモンハンの操虫棍のように、敵や地面、壁に付着させて、効率よく、パレットブレットを飛ばしていきます。

## 使用可能条件
マーカー発射は、PlayerのアクションステートがFreeのときに開始できます。
入力すると、
Free → MarkerAimingに状態が移行します。

## 照準モード
### 挙動
照準モード中は以下の挙動になる。
- 移動は可能
- 通常時より移動速度が低下し、ゆっくり歩く
- カメラがPlayerの肩らへんに近づく
- レティクルを表示する
- Playerの向きが照準方向に追従する
- ジャンプ不可、ダッシュ可（PlayerステートDashへの切り替え）
## 入力方式
マーカー操作には三つの入力方式を用意する。
1. 照準長押し方式→デフォルトではこれ
- 照準入力を押している間、MarkerAiming
- 照準入力を離すと照準終了
- 発射入力でマーカーを発射
- 発射しても照準は終了しない
- 照準入力を押している限り、続けて発射可能

2. 照準切り替え方式

* 照準ボタンを押すと、`Free`から`MarkerAiming`へ移行し、照準モードを開始する。
* 照準中にもう一度照準ボタンを押すと、`MarkerAiming`から`Free`へ戻り、照準モードを終了する。

3. ワンボタン方式

- 照準と発射を同じボタンで行う。
- ボタンを押している間は照準モードになり、ボタンを離して照準を終了すると同時にマーカーを発射する。
## マーカーの発射
### 発射条件
- MarkerAiming中
- 照準長押し方式・照準切り替え方式では、発射入力によって発射する
- ワンボタン方式では、照準ボタンを離したときに発射する
### 発射方向
- マーカーは画面中央のレティクルが示す方向へ発射する。
### 発射位置
- Playerの武器の先端（発射用の場所）から発射する
### Player側で行う処理
- マーカーオブジェクトを生成する
- 発射モーションを再生する
- 発射中に一瞬操作不能になる
- 発射クールタイムを持つ。
