# Player状態

## 目的
### 基本設計方針（ステートマシン）
Playerの行動状態（State）と、状態間の遷移条件を定義します。

Playerの行動はステートマシン（FSM）で管理します。

## 状態別の挙動

各ステートにおける挙動と遷移条件を定義します。正式なクラス分割は実装担当者に一任します。

### 1. Idle（待機）
ゲームプレイの基本となる停止状態です。
* **許可される操作:** すべての基本操作（移動、カメラ操作、マーカー発射、ドローモード開始、会話・調査）
* **状態遷移:**
    * 移動入力が行われた → **Move へ遷移**
    * 攻撃操作が行われた → **Attack へ遷移**
    * ドローモード開始操作が行われた → **Skill（ドローモード）へ遷移**
    * 会話・調査対象にアクションした → **Interact へ遷移**

### 2. Move（移動）
移動・ダッシュ中の状態です。
* **許可される操作:** 移動、カメラ操作、マーカー発射、ドローモード開始
* **状態遷移:**
    * 移動入力がなくなった → **Idle へ遷移**
    * その他、Idleと同様の操作で各ステートへ遷移

### 3. Attack（攻撃）
マーカー発射など、通常攻撃を行っている状態です。
* **状態遷移:**
    * 攻撃アクションが終了した → **Idle または Move へ遷移**

### 4. Skill（スキル / ドローモード）
シャオンダマを繋いで攻撃を準備する（ドローモード等の）状態です。
* **開始処理 (Enter):**
    * BGM以外の世界（環境・敵など）の進行速度を `0.2倍速` に変更する。
* **更新処理 (Update / 制限時間 10秒):**
    * 許可される操作：移動(`WASD`)、なぞり選択（左ドラッグ）、確定/キャンセル操作
    * 例外仕様：BGMは等速で再生。発射された待機コードも等速BGMに同期し、スロー世界の中で動く（確定）。
* **終了処理 (Exit):**
    * 世界の進行速度を等速（1.0倍）に戻す。
* **状態遷移:**
    * 確定操作が行われた → **繋いだシャオンダマを待機コード化して Idle/Move へ遷移**
    * ダッシュ入力、またはキャンセル操作が行われた → **選択中の玉を割らずに解放し Idle/Move へ遷移**
    * 制限時間（10秒）が経過した → **Idle/Move へ遷移**（※確定扱いかキャンセル扱いかは未決）

### 5. Interact（会話・調査）
NPCとの会話やオブジェクトを調べている状態です。
* **許可される操作:** メッセージ送り、選択肢の決定など、UI操作のみ。
* **制限事項:** 移動、攻撃、スキル発動を無効化し、誤動作を防ぎます。
* **状態遷移:**
    * 会話やイベントが終了した → **Idle へ遷移**

### 6. Hit（被ダメージ）
敵の攻撃を受け、被弾リアクションをとっている状態です。
* **状態遷移:**
    * 怯みや無敵時間が終了した → **Idle へ遷移**
    * ※汚染度が満杯になった場合は **Dead へ遷移**

### 7. Dead（死亡）
汚染度が満杯になった状態です。
* **仕様:** プレイヤーの操作を一切受け付けなくなります。
* **状態遷移:**
    * 本ステートに突入後、GameFlow系システムへゲームオーバー処理を委譲します。
