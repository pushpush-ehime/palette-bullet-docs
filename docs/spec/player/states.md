# Player状態

## ページ概要

- 対象担当：プログラム
- 関連ページ：[Player概要](/spec/player/)、[ドローモードへの移行](/spec/player/draw-mode-transition)

## 目的

Playerの行動状態（State）と、状態間の遷移条件を定義します。
※統合仕様書 v3.2（§4.3・§4.10）を正とします。

## 基本設計方針（ステートマシン）

Playerの行動はステートマシン（FSM）で管理します。
なお、「汚染度（HP）」の管理は本ステートマシンとは完全に切り離し、GameFlow系が独立した単一ゲージとして処理します（確定）。

## 状態定義

各ステートにおける挙動と遷移条件を定義します。正式なクラス分割は実装担当者に一任します。

### 1. 通常状態 (State_Normal)

ゲームプレイの基本となる状態です。

* **許可される操作:** すべての基本操作（移動、ダッシュ、カメラ操作、マーカー発射、ドローモード開始）
* **状態遷移:**
    * ドローモード開始操作（右クリック） → **「ドローモード状態」へ遷移**

### 2. ドローモード状態 (State_DrawMode)

シャオンダマを繋いで攻撃を準備する状態です。

* **開始処理 (Enter):**
    * BGM以外の世界（環境・敵など）の進行速度を `0.2倍速` に変更する。
* **更新処理 (Update / 制限時間 10秒):**
    * 許可される操作：移動(`WASD`)、なぞり選択（左ドラッグ）、確定/キャンセル操作
    * 例外仕様：BGMは等速で再生。発射された待機コードも等速BGMに同期し、スロー世界の中で動く（確定）。
* **終了処理 (Exit):**
    * 世界の進行速度を等速（1.0倍）に戻す。
* **状態遷移:**
    * 確定操作が行われた → **繋いだシャオンダマを待機コード化して「通常状態」へ遷移**
    * ダッシュ入力、またはキャンセル操作が行われた → **選択中の玉を割らずに解放し「通常状態」へ遷移**
    * 制限時間（10秒）が経過した → **「通常状態」へ遷移**（※確定扱いかキャンセル扱いかは未決）

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| ドローモードのスロー倍率 | 0.2 | 仮仕様 |
| ドローモードの時間制限 | 10秒 | 仮仕様 |

## 未決事項

- ドローモード時間切れ時の扱い（確定として発射するか、キャンセルとして玉を解放するか）
- 被弾時のリアクション（ノックバック・無敵時間など）を本ステートマシンに組み込むか否か
