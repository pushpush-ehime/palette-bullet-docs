# Player状態

## ページ概要

- 対象担当：プログラム
- 関連ページ：[Player概要](/spec/player/)、[ドローモードへの移行](/spec/player/draw-mode-transition)

## 目的

Playerの状態と状態遷移を定義します。統合仕様書 v3.2（§4.3・§4.10）を正とします。

## プレイヤーから見た挙動

- 通常時は移動・ダッシュ・カメラ操作・マーカー発射ができます。
- ドローモードを開始すると、BGM以外の世界が0.2倍速になり、シャオンダマをなぞって繋げます。ドローモード中も移動できます。
- ドローモードは確定・キャンセル・時間切れで終了し、通常時に戻ります。
- 被弾すると汚染度が増加し、満杯でゲームオーバーになります。

## 詳細仕様

状態一覧（正式な状態分解はクラス設計で確定します）：

| 状態 | 説明 | 状態 |
|---|---|---|
| 通常 | 移動・ダッシュ・カメラ操作・マーカー発射・ドローモード開始が可能 | 確定 |
| ドローモード中 | BGM以外が0.2倍速。なぞり選択と移動が可能。時間制限あり | 確定（倍率・制限時間は仮値） |

状態遷移：

| 遷移 | 条件 | 状態 |
|---|---|---|
| 通常 → ドローモード | ドローモード開始操作（右クリック・仮） | 仮仕様 |
| ドローモード → 通常（確定） | 確定操作。繋いだシャオンダマは待機コードになる | 確定 |
| ドローモード → 通常（キャンセル） | ダッシュまたは終了操作。選択中の玉は割らずに解放する | 確定（玉の解放は仮仕様） |
| ドローモード → 通常（時間切れ） | 制限時間の経過。時間切れ時の扱いは未決 | 未決 |

- 汚染はPlayerの状態遷移とは別の単一ゲージで管理します（確定）。満杯時のゲームオーバーはGameFlow系が扱います。

## 状態別の挙動

### 通常

- すべての基本操作（[入力と操作](/spec/player/input-and-controls)参照）を受け付けます。

### ドローモード中

- BGMは等速のまま再生されます（確定）。
- `W` `A` `S` `D`で移動できます（仮仕様）。
- ドローモード中に待機コードの発射条件が満たされた場合も発射されます。発音は等速BGMに同期し、飛翔はスロー世界側（0.2倍速）で移動します（確定）。

## 例外・禁止事項

- ドローモード中もBGMをスローにしないこと（確定）。
- 未決の遷移（時間切れ時の扱いなど）を推測で確定させないこと。

## パラメータ

| パラメータ | 値 | 状態 |
|---|---|---|
| ドローモードのスロー倍率 | 0.2 | 仮仕様 |
| ドローモードの時間制限 | 10秒 | 仮仕様 |

## 未決事項

- ドローモード時間切れ時の扱い（確定扱いかキャンセル扱いか）
- 被弾時のリアクション（ノックバック・無敵時間）の有無
- 正式な状態分解（クラス設計で確定）
