# Player入力と操作

## ページ概要

- 対象担当：プログラム
- 関連ページ：[Player概要](/spec/player/)、[基本移動](/spec/player/basic-movement)

## 目的

Playerが受け付ける入力と操作を定義します。

## 基本設計方針（キーバインド・マッピング）

**「入力デバイスの特定のボタン（Aボタンなど）に直接依存しない設計」**を原則とします。

*   **アクションマッピングの採用:** 「特定のボタンが押された」ではなく、「特定のアクション（Jump、Attackなど）が入力された」としてプログラム側で受け取れるように、間に仮想的な入力を挟みます。
*   **キーコンフィグの前提:** プレイヤーが将来的にオプション画面で自由にボタン配置を変更（キーバインド設定）できるように、内部の設計を分離しておきます。
*   **マルチデバイス想定:** キーボード＆マウス、各種ゲームパッドなど、入力元が変わってもPlayerのスクリプト自体は変更せずに動く状態を目指します。

## 入力アクション定義とデフォルト設定

操作デバイスのキー・ボタン配置のデフォルト値と、プレイヤーによる変更可否を定義します。
プログラム内部ではキーの直接指定（ハードコード）は避け、以下のアクション名で入力を受け取る設計とします。

| アクション名 | デフォルトキー | 変更可否 | 役割・用途 |
|---|---|---|---|
| Move | W, A, S, D | 固定 | キャラクターの前後左右への基本移動 |
| Jump | Space | 変更可 | ジャンプを行う |
| Dash | Shift | 変更可 | 高速移動・回避 |
| MarkerFire | マウスホイール押し込み(中クリック) | 変更可 | マーカーを発射する |
| DrawMode | 右クリック | 変更可 | ドローモードの開始・終了（※挙動は設定で切替可能） |
| Select | 左クリック | 変更可 | シャオンダマの選択 |

## 特殊な入力挙動（設定・状態による変化）

一部の入力アクションは、オプション設定やキャラクターの状態によって挙動が変化します。

### ドローモード（DrawMode）の操作設定
プレイヤーのオプション設定により、ドローモードの操作タイプを以下の2種類から選択・切り替え可能とします。
1. **トグル方式（クリック）:** 右クリックを押すとドローモード開始。もう一度右クリックを押すと終了。
2. **ホールド方式（長押し）:** 右クリックを押している間だけドローモードになり、離すと終了。

### シャオンダマの選択（Select）
ドローモードのオン/オフ状態によって、左クリック時の選択挙動が変化します。
* **通常時:** 左クリックでシャオンダマを1つだけ選択する。
* **ドローモード中:** ドローモードが有効な状態（右クリック中、またはトグルでオンの状態）で左クリックを使用すると、複数のシャオンダマを選択できる。
