# Player入力と操作

## 1．このページで扱う範囲

このページでは、Playerが使用する入力アクションと、デフォルトの入力割当を定義する。

次の内容は、各機能の仕様ページで定義する。

* 移動速度や向きの制御
* ダッシュの距離や無敵時間
* ドローモード中の処理
* シャオンダマの候補判定
* マーカーの発射処理
* 万能シャオンダマの生成処理
* カメラの移動や回転

## 2．入力設計の基本方針

Playerの処理では、特定のキーやボタンを直接参照しない。

「移動」「ダッシュ」「ドローモード開始」などの入力アクションを受け取り、対応する機能へ処理を要求する。

入力は、次の方針で管理する。

* キーコンフィグによる割当変更を前提とする
* キーボード・マウスとゲームパッドで同じ入力アクションを使用する
* 入力デバイスが変わっても、Player側の処理を変更しない
* 現在のPlayer状態で許可されていない入力は受け付けない

## 3．Player入力アクション一覧

| 入力アクション       | 内容                  |
| ------------- | ------------------- |
| Move          | Playerの移動を要求する      |
| Look          | カメラ操作を要求する          |
| Dash          | ダッシュの開始を要求する        |
| DrawMode      | ドローモードの開始または終了を要求する |
| Trace         | シャオンダマのなぞり操作を行う     |
| TraceConfirm  | なぞったシャオンダマの確定を要求する  |
| Marker        | マーカーの発射を要求する        |
| UniversalNote | 万能シャオンダマの生成を要求する    |

## 4．デフォルト入力割当

| 入力アクション       | 操作内容        | デフォルト入力         | 仕様状態 |
| ------------- | ----------- | --------------- | ---- |
| Move          | 移動          | `W` `A` `S` `D` | 確定   |
| Look          | カメラ操作       | マウス移動           | 仮仕様  |
| Dash          | ダッシュ・回避     | `Left Shift`    | 仮仕様  |
| DrawMode      | ドローモード開始・終了 | 右クリック           | 仮仕様  |
| Trace         | シャオンダマのなぞり  | 左ボタンを押したままマウス移動 | 仮仕様  |
| TraceConfirm  | なぞった構成の確定   | 左ボタンを離す         | 仮仕様  |
| Marker        | マーカー発射      | マウスホイール押し込み     | 確定   |
| UniversalNote | 万能シャオンダマ生成  | `Q`             | 仮仕様  |

ドローモード中は画面上を移動するカーソルを使用しない。

マウス移動によってカメラを操作し、画面中央のレティクルをシャオンダマの選択位置として使用する。

## 5．状態別の入力可否

| 入力アクション       | Normal | Dash | Hit | Draw | Conversation | Cutscene | Result |
| ------------- | :----: | :--: | :-: | :--: | :----------: | :------: | :----: |
| Move          |    ○   |   ×  |  ×  |   ○  |       ×      |     ×    |    ×   |
| Look          |    ○   |   ○  |  ○  |   ○  |      未決      |     ×    |    ×   |
| Dash          |    ○   |   ×  |  ×  |  ○※  |       ×      |     ×    |    ×   |
| DrawMode      |    ○   |   ×  |  ×  |   ○  |       ×      |     ×    |    ×   |
| Trace         |    ×   |   ×  |  ×  |   ○  |       ×      |     ×    |    ×   |
| TraceConfirm  |    ×   |   ×  |  ×  |   ○  |       ×      |     ×    |    ×   |
| Marker        |    ○   |   ×  |  ×  |   ×  |       ×      |     ×    |    ×   |
| UniversalNote |    ○   |   ×  |  ×  |   ×  |       ×      |     ×    |    ×   |

* `○`：入力を受け付ける
* `×`：入力を受け付けない
* `未決`：仕様が確定していない
* `※`：Draw中にDash入力を受け付けた場合は、DrawをキャンセルしてからDashへ移行する
