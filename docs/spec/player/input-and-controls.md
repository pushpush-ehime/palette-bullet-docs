# Player入力と操作

## ページ概要

- 対象担当：プログラム
- 関連ページ：[Player概要](/spec/player/)、[基本移動](/spec/player/basic-movement)

## 目的

Playerが受け付ける入力と操作、および入力実装の基本設計方針を定義します。統合仕様書 v3.2（§4.3.8・§4.6.1・§4.10）を正とします。

## プレイヤーから見た挙動

- `W` `A` `S` `D` で移動します。
- ダッシュ（回避）ができます。
- マウスでカメラを操作します。
- 右クリックでドローモードを開始し、左ドラッグでシャオンダマをなぞって繋ぎます。
- マウスホイール押し込みでマーカーを発射します。
- `Q` スキルで万能シャオンダマを生成します。

## 詳細仕様

### 基本設計方針（キーバインド・マッピング）

「入力デバイスの特定のボタン（キー）とアクションを直接紐づけない（ハードコードしない）こと」を**絶対の原則**とします。

*   **アクションマッピングの採用:** プログラム側では「特定のボタンが押された」と直接判定するのではなく、「Jumpアクションが入力された」「Attackアクションが入力された」といった抽象化されたアクション名でイベントを受け取れるように設計してください。
*   **キーコンフィグの前提:** 将来的にプレイヤーがオプション画面で自由にボタン配置（キーバインド）を変更できる状態を前提として実装を進めてください。
*   **マルチデバイス想定:** キーボード＆マウス、各種ゲームパッドなど、入力元が変わってもPlayerのスクリプト自体は一切変更せずに動く状態を目指します。

### デフォルトの入力割当

以下はアクションマッピングにおけるデフォルトのバインドです。

| 操作 | 入力 | 状態 |
|---|---|---|
| 移動 | `W` `A` `S` `D` | 確定 |
| ダッシュ（回避） | 割当は設計書V2を暫定踏襲 | 仮仕様 |
| カメラ操作 | マウス移動（設計書V2を暫定踏襲） | 仮仕様 |
| ドローモード開始 | 右クリック | 仮仕様 |
| シャオンダマのなぞり | 左ドラッグ | 仮仕様 |
| ドローモード確定・終了 | 設計書V2を暫定踏襲 | 仮仕様 |
| マーカー発射 | マウスホイール押し込み | 確定 |
| 万能シャオンダマ生成スキル | `Q` | 仮仕様 |

- 入力は設計書V2の入力一元化方針を踏襲し、マーカー入力を既存のInput Mapへ追加します（確定）。

## 状態別の挙動

- 通常時：移動・ダッシュ・カメラ操作・マーカー発射・ドローモード開始を受け付けます。
- ドローモード中：なぞり・確定・キャンセル操作と移動を受け付けます。ダッシュ入力はドローモードのキャンセルとして扱います（詳細は[Player状態](/spec/player/states)）。

## 例外・禁止事項

- 入力デバイスの特定のボタンとアクションを直接紐づけない（ハードコードしない）こと。
- マーカー操作（ホイール押し込み）を既存入力と競合させないこと（確定）。
- 表で「仮仕様」の割当を実装者が勝手に確定させないこと。変更する場合は企画確認を経て仕様書の版を上げます。
