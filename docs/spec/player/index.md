# Player概要

## 目的

Palette Bulletにおいて、Playerがゲーム内で担う役割と、Playerカテゴリで管理する仕様の範囲を定義します。

移動、入力、状態、ダッシュなどの詳しい挙動は、Playerカテゴリ内の各仕様ページで定義します。

## Playerの役割

Playerは、シャオンダマを使って攻撃を構成する**指揮者**です。

ゲーム側がBGMの進行を管理し、Playerは使用するシャオンダマを選んで、鳴らす音と攻撃の構成を決めます。

Player自身が連続して攻撃するのではなく、主に次の行動を担当します。

* 敵の攻撃を避けながら戦場を移動する
* 周囲にあるシャオンダマを探す
* ドローモードでシャオンダマを選択する
* 選択したシャオンダマから攻撃構成を作る
* マーカーを使って攻撃先を指定する
* BGMとの一致による発射に備えて位置を調整する
* 必要に応じて万能シャオンダマ生成スキルを使用する

## 基本的な行動の流れ

1. 戦場を移動し、敵の攻撃を避けます。
2. 周囲にあるシャオンダマの位置を確認します。
3. ドローモードを開始します。
4. 使用するシャオンダマをなぞって選択します。
5. 選択を確定し、攻撃構成を待機させます。
6. 必要に応じて敵へマーカーを付けます。
7. BGMとの一致によって、待機中の攻撃構成が発射されます。
8. 敵が浄化されるまで、この流れを繰り返します。

シャオンダマの選択判定、攻撃構成、BGMとの一致、発射処理の詳細は、Playerカテゴリでは定義しません。

## Playerの状態

Playerの操作は、大きく次の状態に分けます。

| 状態       | 概要                       |
| -------- | ------------------------ |
| Gameplay | 移動、回避、マーカー操作などを行う通常の戦闘状態 |
| Draw     | シャオンダマを選択し、攻撃構成を作る状態     |
| Result   | クリアまたはゲームオーバー後の状態        |

各状態で使用できる操作、状態の開始条件、終了条件、遷移の優先順位は、[Player状態と操作制限](/spec/player/states)で定義します。

## Playerカテゴリで扱う範囲

Playerカテゴリでは、次の仕様を扱います。

* Playerが受け取る入力
* デフォルトの操作割当
* Playerの状態と操作制限
* Playerの移動と向き
* ダッシュと回避
* ドローモード開始・確定・キャンセル時のPlayer制御
* マーカーを発射するためのPlayer操作
* 万能シャオンダマ生成スキルの発動
* 被弾、汚染、行動不能
* 他システムへ処理を要求するときの条件
* 他システムから結果を受け取ったときのPlayerの反応

## 他システムとの役割分担

| システム        | Playerが担当すること      | 接続先が担当すること             |
| ----------- | ------------------ | ---------------------- |
| 入力システム      | 入力アクションを受け取る       | キーやボタンからアクションへ変換する     |
| カメラ         | 移動状態やPlayer位置を通知する | 追従、回転、距離、画角を制御する       |
| ドローシステム     | 開始、確定、キャンセルを要求する   | 候補判定、なぞり選択、攻撃構成を管理する   |
| シャオンダマ・音楽連動 | 万能シャオンダマの生成を要求する   | 音、色、生成、待機構成、BGM一致を管理する |
| 戦闘          | マーカー操作や被弾結果を受け取る   | 攻撃先、弾丸、命中、浄化を管理する      |
| 敵           | 被弾結果を受け取る          | 敵の行動、攻撃、状態を管理する        |
| UI          | Playerの状態を通知する     | 汚染度、クールタイム、操作案内などを表示する |
| 演出          | 状態変化や行動開始を通知する     | アニメーション、エフェクト、効果音を再生する |

## Playerカテゴリで扱わない範囲

次の内容は、Playerカテゴリでは詳細を定義しません。

* キャラクターの名前、年齢、出身、背景設定
* キャラクターのビジュアルデザイン
* カメラの追従位置、距離、画角、回転速度
* シャオンダマの候補判定
* なぞり線とシャオンダマの接触判定
* コードの成立条件
* 音と色の決定方法
* BGMとの一致判定
* 待機構成の管理
* 発射する弾丸の飛翔処理
* 攻撃対象の抽選
* 敵への命中と浄化判定
* UIの配置やデザイン
* アニメーション、エフェクト、効果音の具体的な制作内容

これらは、それぞれを担当する仕様カテゴリで定義します。

## 例外・禁止事項

* Playerの処理から、特定のキーやボタンを直接参照しません。
* 他カテゴリが担当する判定や処理を、Player側へ重複して実装しません。
* Player側でBGMとの一致判定を行いません。
* Player側で攻撃対象や命中結果を独断で決定しません。
* Result状態では、戦闘に関するPlayer操作を受け付けません。
* 仕様が不足している場合は、担当者の判断だけで挙動を追加しません。
* 他ページと仕様が矛盾した場合は、実装前に未決事項として記録します。

## パラメータ

Playerカテゴリ全体で共通する数値パラメータはありません。

移動速度、ダッシュ性能、クールタイム、無敵時間などは、それぞれの詳細仕様ページで定義します。

## 未決事項

* Playerの耐久値を汚染度だけで管理するか、HPを併用するか
* 会話やオブジェクト調査をプロトタイプのPlayer機能に含めるか
* 万能シャオンダマ生成スキルをPlayerカテゴリとシャオンダマカテゴリのどちらで主に管理するか
