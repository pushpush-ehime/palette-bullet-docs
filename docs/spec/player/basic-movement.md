# Player基本移動

## ページ概要

- 対象担当：プログラム
- 関連ページ：[入力と操作](/spec/player/input-and-controls)、[カメラとの接続](/spec/player/camera-connection)

## 目的

プレイヤーが3D空間を移動する際の、入力方法と基本動作を定義します。統合仕様書 v3.2（§4.10.1・§4.3.6・§4.3.7）を正とします。

## プレイヤーから見た挙動

- `W` `A` `S` `D`で移動します。
- ダッシュ（回避）で素早く移動できます。
- 入力をやめると停止します。
- ドローモード中も移動できます。
- ドローモード中にダッシュすると、ドローモードがキャンセルされます。

## 詳細仕様

| 項目 | 内容 | 状態 |
|---|---|---|
| 対応プラットフォーム | PC | 確定 |
| 視点 | 三人称視点 | 確定 |
| 移動入力 | `W` `A` `S` `D` | 確定 |
| ダッシュ（回避） | あり（設計書V2の実装を踏襲） | 確定 |
| ダッシュの速度・距離・クールタイム | 未決 | 未決 |
| 通常移動速度 | 未決 | 未決 |
| 斜め移動時の速度補正 | 必要 | 仮仕様 |
| ドローモード中の時間倍率 | 0.2倍 | 確定（倍率の値は仮値） |
| ドローモード中の移動 | `W` `A` `S` `D`で可能 | 仮仕様 |

## 状態別の挙動

### 通常時

- `W`で前方へ移動します。
- `S`で後方へ移動します。
- `A`と`D`で左右へ移動します。
- ダッシュ（回避）ができます。

### ドローモード中

- `W` `A` `S` `D`で移動できます。
- 時間の進行速度は通常時の0.2倍です。
- ダッシュするとドローモードがキャンセルされ、選択中のシャオンダマは割らずに解放されます。

## 例外・禁止事項

- 斜め入力で移動速度が速くならないようにします。

## パラメータ

| パラメータ | 値 |
|---|---|
| 通常移動速度 | 未決 |
| ダッシュの速度・距離・クールタイム | 未決 |
| ドローモード中の時間倍率 | 0.2 |

## 未決事項

- 通常移動速度
- ダッシュの性能値（速度・距離・クールタイム・無敵時間の有無）
- 加速と減速を使用するか
- 移動方向をカメラ基準にするか
- 壁や段差との衝突ルール
