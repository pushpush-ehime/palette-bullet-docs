# Player基本移動

## 目的

プレイヤーが3D空間を移動する際の、入力方法と基本動作を定義します。

## プレイヤーから見た挙動

- カメラに対して`W` `A` `S` `D`でそれぞれ前、左、後ろ、右に移動。---スプラや原神と一緒
- ダッシュ（回避）で素早く移動。
- 入力をやめると停止。
- ドローモード中も移動可能。
- ドローモード中にダッシュすると、ドローモードがキャンセルされる。

## 詳細仕様

移動担当の方が調べてここに記載してください。

## 状態別の挙動

### 通常時

- `W`で前方へ移動します。
- `S`で後方へ移動します。
- `A`と`D`で左右へ移動します。
- ダッシュ（回避）ができます。

### ドローモード中

- `W` `A` `S` `D`で移動できます。
- 時間の進行速度は通常時の0.2倍です。
- ダッシュするとドローモードがキャンセルされ、選択中のシャオンダマは割らずに解放されます。

## パラメータ

| パラメータ | 値 |
|---|---|
| 通常移動速度 | 未決 |
| ダッシュの速度・距離・クールタイム | 未決 |
| ドローモード中の時間倍率 | 0.2 |

## 未決事項

- 通常移動速度
- ダッシュの性能値（速度・距離・クールタイム・無敵時間の有無）
- 加速と減速を使用するか
- 壁や段差との衝突ルール
