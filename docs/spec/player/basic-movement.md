# Player基本移動

## 目的

Playerの基本移動について、参考ゲームだけでは伝わらない仕様や、実装時に注意が必要な点のみを定義します。

一般的な3Dアクションゲームと同様の挙動は、このページでは詳しく説明しません。

## 確認が必要な仕様

### 1．通常移動の参考ゲーム

基本移動は、『スプラトゥーン』や『原神』と同様のカメラ基準移動を想定しています。

* `W` `A` `S` `D`で移動します。
* カメラの向きを基準に移動方向が決まります。

### 2．ドローモード中のPlayer速度

ドローモード中は、BGM以外のゲーム進行速度が通常時の0.2倍になります。

Playerの移動も0.2倍速になります。

### 3．ダッシュによるキャンセルの処理順

ドローモード中にダッシュした場合は、次の順番で処理することを想定しています。

1. ドローモードを解除する。
2. 選択中のシャオンダマを消費せずに解放する。
3. ゲームの進行速度を通常に戻す。
4. ダッシュを実行する。

ダッシュの速度、距離、クールタイム、無敵時間などの詳細は、別の仕様ページで定義します。

### 4．通常移動中のPlayerの向き

* 移動方向を向く。
* 『原神』と同様の挙動にする。

### 5．基本移動に関係する特殊な制限

* マーカーの発射中→打ちながら移動は通常に比べて減速。レティクルモードはさらに減速。
* 写音玉生成スキルの使用中→スキルがそもそもあるか未定！
* 被弾中→移動不可！やられモーション中はカメラ移動しかできません。
