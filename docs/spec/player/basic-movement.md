## 1．目的

プレイヤーが3D空間を移動する際の、入力方法と基本的な動作を定義します。

## 2．仕様一覧

| 項目 | 内容 | 状態 |
|---|---|---|
| 対応プラットフォーム | PC | 確定 |
| 移動入力 | `W` `A` `S` `D` | 確定 |
| 通常移動速度 | 未決 | 未決 |
| 斜め移動時の速度補正 | 必要 | 仮仕様 |
| Draw Mode中の時間倍率 | 0.2倍 | 確定 |
| Draw Mode中の移動 | `W` `A` `S` `D`で可能 | 確定 |

## 3．基本ルール

### 3.1 通常移動

- `W`で前方へ移動します。
- `S`で後方へ移動します。
- `A`と`D`で左右へ移動します。
- 入力をやめると移動を停止します。
- 斜め入力で移動速度が速くならないように補正します。

### 3.2 Draw Mode中の移動

Draw Mode中も、プレイヤーは`W` `A` `S` `D`で移動できます。

時間の進行速度は通常時の0.2倍になります。
