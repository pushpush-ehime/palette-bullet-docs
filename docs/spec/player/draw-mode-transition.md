# Playerアクション｜パリィ

## 目的

このページでは、パリィの開始条件、成功・失敗時の処理、操作制限、終了条件を定義します。

## パリィとは

パリィボタンを押すと、Playerはパリィアクションを実行します。

パリィは、敵の攻撃が来ていない場合でも実行できます。敵の攻撃に対して適切なタイミングで実行すると、パリィが成功します。

敵の攻撃に対するパリィ結果は、リズムに対する入力タイミングによって段階的に評価します。

## 使用可能条件

パリィは、Playerが地上にいる場合のみ使用できます。

空中では使用できません。

## パリィの開始

パリィ入力を受け付けると、Playerは即座にPlayerステート`Parrying`へ移行し、パリィモーションを開始します。

パリィ開始時のPlayerの向きを、モーションが終了するまで維持します。

パリィ判定が始まるまでの時間と、判定が有効な時間は、調整可能なパラメータとして管理します。

## パリィ中の挙動

パリィモーションが終了するまで、Playerは移動できません。

パリィ中は、次のアクションを使用できません。

* 移動
* ジャンプ
* ダッシュ
* チャージ
* マーカー照準

パリィ中に足場から落下した場合は、パリィを終了して`Airborne`へ移行し、落下モーションを再生します。

パリィ中に被弾した場合は、パリィを終了して`Hit`へ移行します。

## パリィの成功・失敗

### 成功

パリィ判定が有効なタイミングで敵の攻撃を受けると、パリィが成功します。

パリィに成功した攻撃のダメージは、完全に無効化します。

成功時に硬直や専用のパリィモーションは追加せず、実行中のパリィモーションを継続します。

### 失敗

パリィ判定が有効ではないタイミングで敵の攻撃を受けた場合は、通常どおり被弾します。

被弾した場合は、`Parrying`を終了して`Hit`へ移行します。

### 空振り

パリィモーション中に敵の攻撃を受けなかった場合は、空振りとして扱います。

空振りの場合も、パリィモーションが終了するまで、ほかのアクションは使用できません。

## パリィの終了

パリィは、次のいずれかの条件で終了します。

* パリィモーションが終了する
* Playerが被弾する
* パリィ中に足場から落下する

パリィモーションが正常に終了した場合は、`Free`へ戻ります。

被弾した場合は`Hit`、足場から落下した場合は`Airborne`へ移行します。

## 連続パリィ

パリィ入力は、リズムゲームのように連続して行えます。

パリィの成功後も、すぐに次のパリィ入力を受け付けます。空振りの場合も、続けてパリィを実行できます。

連続パリィ中は、パリィ以外のアクションへ移行できません。最後に入力したパリィのモーションが終了すると、`Free`へ戻ります。

## 他のアクションとの切り替え

パリィは、ダッシュ、ジャンプ、チャージ、マーカー照準によってキャンセルできません。

これらのアクションへ移行できるのは、パリィモーションが終了した後です。

ただし、ダッシュについては、ほかのアクションより早いタイミングから入力を受け付ける可能性があります。

## パラメータ

| パラメータ                 | 内容                 | 値  |
| --------------------- | ------------------ | -- |
| ParryMotionDuration   | パリィモーション全体の時間      | 未定 |
| ParryStartup          | 入力からパリィ判定が始まるまでの時間 | 未定 |
| ParryWindow           | パリィ判定が有効な時間        | 未定 |
| ParryEvaluationWindow | 段階評価に使用するタイミングの範囲  | 未定 |

## 未決事項

* （未確定）パリィの段階評価を何段階にするか
* （未確定）段階評価ごとのタイミング範囲と効果
* （未確定）体当たりなど、邪音玉飛ばし以外の攻撃をパリィした場合に敵をひるませるか
* （未確定）戦闘BGMとの同期を維持したまま、パリィ成功時のHitStopや敵のひるみを実装するか
* （未確定）パリィモーション終了前に、ダッシュ入力を受け付ける時間を設けるか
* （未確定）パリィ中に入力されたダッシュやマーカー照準を無視するか、パリィ終了後まで保存するか
* （未確定）連続パリィ時に、モーションを最初から再生するか、専用の連続モーションへ移行するか
