# ドローモード

## ドローモード開始
### FPS視点
カメラがグンと寄ってFPS視点になる

### 移行可能条件
1. 地面にいるとき
2. スタミナが余っているとき

## ドローモード中
### 複数の写音玉を選択可能

### 以下の行動でキャンセル、もしくは終了
1. ダッシュ
2. 弾丸化完了
3. 被弾

## ドローモード終了
### カメラ
カメラが元の位置に戻る。
## ドローモード中のカメラ

FPS（一人称）視点に移行し、画角を広げる。カメラ回転はそのままなぞり入力を兼ねる。

詳細は [ドローモード時のカメラ](/spec/camera/draw-mode) を参照（本ページでは定義しない）。
