# シャオンダマの選択

## 選択＝”弾丸化（パレットブレット）”＝攻撃
シャオンダマを選択すると、空間上に固定され、リズムよく
マーカーに向かって飛んでいく。
## 選択の仕様
選択は照準（画面中央のレティクル）に入ったシャオンダマをクリックすることで可能。
狙いはカメラを振って合わせる（画面上を自由に動くカーソルは使わない）。詳細は [ドローモード時のカメラ](/spec/camera/draw-mode) を参照。

## 二種類の選択
#### 1. クリック選択
クリック選択は一つのシャオンダマを弾丸（パレットブレット）化するときに使用する。浮遊しているシャオンダマにレティクルを合わせてクリック。

#### 2. なぞって選択
なぞって選択は複数のシャオンダマを同時に弾丸化する(コードを構成)するときに使用する。
左ボタンを押したままカメラを振り、レティクルが通過したシャオンダマを順に繋ぐ。
