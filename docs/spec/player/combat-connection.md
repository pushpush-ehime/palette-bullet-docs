# 戦闘状態との接続

## 戦闘状態への移行

敵の索敵や戦闘開始条件は、一般的な3Dアクションゲーム「ゼルダ」「パルテナの鏡」「原神」と同様とします。

具体的な判定は、Enemyまたは戦闘システム側の仕様で定義します。

## 戦闘開始時の変化

戦闘開始時に、通常BGMから戦闘BGMへ切り替わります。

戦闘BGMの進行に合わせてシャオンダマが生成され、BGMの発音イベントと一致した待機構成が発射されます。

BGMの切り替えとシャオンダマ生成を開始する正確なタイミングは、「未決」、です。

## 戦闘状態に依存しない操作

戦闘中・非戦闘中にかかわらず、次の操作ができます。

- ドローモードへの移行
- シャオンダマの選択
- シャオンダマの弾丸化

## 戦闘終了時

戦闘終了時に、次をどう処理するか
- フィールド上に残ったシャオンダマ→そのまま放置（一定距離離れると消える。）
- 発射を待機している構成→（レティクルの方向に飛んでいく。）
- 敵に付与したマーカー→
