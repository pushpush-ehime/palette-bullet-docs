# 戦闘状態との接続

## 戦闘状態の管理

戦闘システムは、次の状態を管理する。

- `NonCombat`：非戦闘状態
- `Combat`：戦闘状態

戦闘状態はPlayerの行動ステートとは別に管理する。

Playerは戦闘状態を保持せず、戦闘システムから状態の変化を受け取る。

## 戦闘状態への移行

敵の索敵や戦闘開始条件は、『ゼルダ』『新・光神話 パルテナの鏡』『原神』などの一般的な3Dアクションゲームと同様とする。

具体的な判定は、Enemyまたは戦闘システム側の仕様で定義する。

## 戦闘開始時

`NonCombat`から`Combat`へ移行したとき、次の処理を開始する。

- 通常BGMから戦闘BGMへ切り替える
- 戦闘BGMに合わせてシャオンダマを生成する
- BGMの発音イベントと一致した待機構成を発射する

BGMの切り替えとシャオンダマ生成を開始する正確なタイミングは未決。

## 戦闘状態に依存しない操作

戦闘中・非戦闘中にかかわらず、次の操作を行える。

- ドローモードへの移行
- シャオンダマの選択
- シャオンダマの弾丸化

## 戦闘終了時

`Combat`から`NonCombat`へ移行したとき、次の処理を行う。

- フィールド上のシャオンダマは残す
- 残ったシャオンダマはPlayerから一定距離離れると消滅する
- 発射を待機している構成は、レティクルの方向へ発射する
- 敵に付与したマーカーを解除する

## 戦闘開始時の変化

戦闘開始時に、通常BGMから戦闘BGMへ切り替わります。

戦闘BGMの進行に合わせてシャオンダマが生成され、BGMの発音イベントと一致した待機構成が発射されます。

BGMの切り替えとシャオンダマ生成を開始する正確なタイミングがこのステートの切り替えタイミングです。

## 戦闘状態に依存しない操作

戦闘中・非戦闘中にかかわらず、次の操作ができます。

- ドローモードへの移行
- シャオンダマの選択
- シャオンダマの弾丸化
