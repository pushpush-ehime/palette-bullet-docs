# BGM 攻撃イベント仕様
## 攻撃イベント

作曲者は、曲中のコード・アルペジオから攻撃に使用したい箇所を指定できる。

#### 例1 指定イベント
##### この曲のこの「コード・アルペジオ」は攻撃に絶対したい！場合

C → E → G
↓
攻撃イベントとして指定

指定された箇所では、ゲーム側が事前に必要な音を表示し、その演奏タイミングで攻撃判定を行う。

#### 例2 ランダム区間
##### こっからこの間に一回は攻撃させときたいなーの場合
作曲者は、ゲーム側が自由に攻撃イベントを選択してよい区間を指定できる。

::: tip
通常区間

ランダム区間 START

8小節の間

ランダム区間 END

通常区間に戻る
:::

ランダム区間内では、曲中のコード・アルペジオからUnity側が攻撃対象を選択する。

### 作曲者が指定するもの(Composer)
- 固定の攻撃タイミング
- 攻撃に使用するコード / アルペジオ
- ランダム区間の開始位置
- ランダム区間の終了位置

### Unity側で決めるもの(Programmer)
- 何拍前にUIへ表示するか
- ランダム区間から何個選ぶか
- どの候補を選ぶか
- プレイヤーが必要音を持っているか
- 攻撃の発生処理
