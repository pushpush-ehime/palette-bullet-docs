# ゲーム全体

## ページ概要


- 対象担当：全担当
- 関連ページ：[ゲーム概要](/game-overview)、[仕様・設計一覧](/spec/)

## 目的

ゲーム開始から終了までの基本的な流れと、各システムの役割・接続関係を定義します。

個別機能の詳しい挙動は、それぞれの仕様ページで定義します。

## プレイヤーから見た挙動


| 項目 | 内容 | 状態 |
|---|---|---|
| ゲーム形式 | 色と音を使って敵を浄化する3Dアクション | 確定 |
| プレイヤーの役割 | 戦場を移動し、シャオンダマをつないで攻撃を構成する | 確定 |
| コア体験 | 色と音で世界をつなぐ爽快ドローアクション | 確定 |
| 戦闘の目的 | 敵を浄化し、ステージのクリアを目指す | 確定 |

## 詳細仕様
1. 戦闘を開始する
2. ラジクジラがBGMをもとにシャオンダマを生成する
3. プレイヤーが敵の攻撃を避けながら配置を確認する
4. ドローモードでシャオンダマを選択する
5. 選択したシャオンダマから攻撃構成を作る
6. BGMの一致イベントに合わせて攻撃する
7. 敵の状態とクリア条件を判定する
8. クリアまたはゲームオーバーまで繰り返す

詳しい判定は、各システムの仕様ページで定義します。

## 状態別の挙動

| 状態 | 内容 | 状態中に動作する主なシステム |
|---|---|---|
| 戦闘開始前 | ステージと戦闘を準備する | ステージ、敵、BGM、UI |
| 通常戦闘 | 移動・回避・状況確認を行う | Player、カメラ、敵 |
| ドローモード | シャオンダマを選択する | Player、ドロー、シャオンダマ |
| 攻撃処理 | 構成した攻撃を発射する | BGM、戦闘、敵、演出 |
| クリア | ステージクリア処理を行う | UI、演出、ステージ |
| ゲームオーバー | 戦闘終了処理を行う | UI、演出、ステージ |

## クリア・ゲームオーバー

| 判定 | 条件 | 判定後 |
|---|---|---|
| クリア | ステージ内の全敵を浄化する | クリア状態へ移行 |
| ゲームオーバー | 汚染度が上限に達する | ゲームオーバー状態へ移行 |

## 例外・禁止事項

- クリアまたはゲームオーバーが確定したら、戦闘操作を停止します。
- 状態が切り替わったときは、Player・敵・BGM・UIへ変更を通知します。
- 個別仕様がこのページと矛盾する場合は、矛盾を未決事項として記録します。
