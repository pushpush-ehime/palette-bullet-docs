# PB-PLY-001：プレイヤーの基本移動を実装する

## 2．目的

プレイヤーがキーボード入力によって、ゲーム空間内を移動できる状態にします。

## 3．実装内容

- `W` `A` `S` `D`の入力を受け取る
- 入力方向にPlayerを移動させる
- 移動速度をInspectorから変更できるようにする
- 斜め移動時の速度を補正する
- 入力をやめたときに移動を停止させる

## 4．対象外

このタスクでは、以下を実装しません。

- ジャンプ
- ダッシュ
- Draw Modeへの切り替え
- 移動アニメーション
- 足音
- カメラ演出

## 5．完了条件

- [ ] `W` `A` `S` `D`でPlayerが移動できる
- [ ] 入力をやめると停止する
- [ ] 斜め移動だけ速くならない
- [ ] 移動速度をInspectorから変更できる
- [ ] Consoleに新しいエラーが発生しない
- [ ] 関連仕様ページの内容と矛盾していない

## 6．確認方法

1. Unityで確認用シーンを開きます。
2. Play Modeを開始します。
3. `W` `A` `S` `D`を順番に入力します。
4. 前後左右へ正しく移動することを確認します。
5. `W`と`D`を同時に押し、斜め移動だけ速くならないことを確認します。
6. Inspectorで移動速度を変更し、移動速度へ反映されることを確認します。
