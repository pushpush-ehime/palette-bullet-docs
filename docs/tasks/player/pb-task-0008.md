## 実装時の注意点

- 移動やジャンプの処理からキーボードを直接参照しないでください。
- キーの割り当てをコードへ直接記述しないでください。
- 将来の入力追加を想定しますが、必要のない共通化や複雑な仕組みは作成しません。
