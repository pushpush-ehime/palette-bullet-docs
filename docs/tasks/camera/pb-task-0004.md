# PB-TASK-0004｜ダッシュ時のカメラFOV変動を実装する

## タスクの目的

ダッシュ（約0.2秒の一発回避）に合わせてFOVを一瞬だけ広げ、疾走感を出します。長押しスプリントではないため、「入力中は広いまま維持」ではなく一発のパルスとして作ります。

## 完成時にできるようになること

- ダッシュした瞬間に視界がふっと広がります。
- ダッシュが終わると、緩やかに元の画角へ戻ります。
- カメラとキャラクターの距離・位置関係は変わりません。
- ドローモードのスロー中でも、広がり方・戻り方の速さが変わりません。

## 実施内容

- Player側のダッシュ開始・終了の状態変化を受け取る
- ダッシュ開始でFOVを水平95度相当（Unityの垂直FOVで約63度）へ拡大する
- ダッシュ終了後、通常のFOVへ戻す
- 「開き時間」と「戻り時間」を別々のパラメータにし、戻り時間を開き時間より長くする
- 補間に`Time.unscaledDeltaTime`を使う
- FOVは常に現在値からその時点の目標値へ補間する方式にする（他の状態と競合しても破綻しないようにするため）
- FOV値と開き・戻り時間をInspectorから調整できるようにする

## 対象範囲

- ダッシュ中のFOV変動と、その行き帰りの補間
- 上記のパラメータ化

## 対象外

- 距離・オフセットの変動（ダッシュでは変えない仕様です）
- ダッシュそのものの移動処理・モーション
- 速度線・モーションブラーなどのエフェクト
- ドローモード時のFOV（PB-TASK-0005）

## 完了条件

- [ ] ダッシュ開始でFOVが広がる
- [ ] ダッシュ終了後にFOVが通常値へ戻る
- [ ] 戻りが開きより緩やかである
- [ ] ダッシュ中もカメラとキャラクターの距離が変わらない
- [ ] スロー中にダッシュしても、広がり・戻りの速さが通常時と同じに見える
- [ ] FOV値・開き時間・戻り時間をInspectorから変更できる
- [ ] Consoleに新しいエラーが発生しない
- [ ] 関連仕様と矛盾していない

## 確認手順

1. Unityで確認用シーンを開きます。
2. Play Modeを開始します。
3. ダッシュを入力し、視界が一瞬広がって戻ることを確認します。
4. ダッシュ中にカメラ距離が変わっていないことを確認します。
5. ドローモードに入ってスロー状態にし、そこからダッシュでキャンセルします。
6. FOVの広がり・戻りの速さが通常時と変わらないことを確認します。
7. Inspectorで開き時間・戻り時間を変更し、挙動へ反映されることを確認します。
8. Consoleに新しいエラーが出ていないことを確認します。

## 前提・依存タスク

## 実装時の注意点

- 数値をハードコードしないでください。すべて`[SerializeField]`またはScriptableObjectでInspector調整可能にします。
- 補間に`Time.deltaTime`を使わないでください。スロー中に演出が5倍遅く見えます。
- ダッシュ中にFOVを広げたまま維持しないでください（長押しスプリント型の挙動にはしません）。
