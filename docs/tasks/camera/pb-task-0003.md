# PB-TASK-0003｜TPSカメラの基本動作を実装する

## タスクの目的

通常時のTPSカメラを実装します。以降のカメラ演出（ダッシュ時・ドローモード時）はすべてこのカメラを土台にするため、最初に作るタスクです。

## 完成時にできるようになること

- キャラクターの右肩越しにカメラが配置され、前方の視界が確保されます。
- マウス／右スティックでカメラを自由に回せます。
- 見上げ・見下ろしに制限がかかり、カメラが宙返りしません。
- 移動入力を入れると、キャラクターがカメラ基準の移動方向へ向き直ります。
- 距離・オフセット・FOV・感度をInspectorから変更できます。

## 実施内容

- 注視点（キャラクターの頭の少し上・右肩越し）とカメラ距離を設定する
- 左右回転（ヨー）を制限なしで回せるようにする
- 上下回転（ピッチ）に上限`+70度`・下限`-45度`の制限をかける
- FOVを水平85度相当（Unityの垂直FOVで約54.5度）に設定する
- 移動入力があるとき、キャラクターをカメラ基準の移動方向へ補間で向き直らせる
- カメラ感度（X/Y独立）と軸反転をパラメータとして用意する
- 距離・オフセット・FOV・ピッチ制限・感度・向き直り速度をInspectorから調整できるようにする

## 対象範囲

- 通常状態のカメラ配置・追従・回転
- カメラ基準の移動方向へのキャラクターの向き直り
- 上記のパラメータ化

## 対象外

- ダッシュ時のFOV変動（PB-TASK-0004）
- ドローモード時のFPS切り替え（PB-TASK-0005）
- 障害物処理（壁越しの遮蔽・カメラのめり込み対策）
- エイム／マーカー投擲時のカメラ
- オプション設定画面のUI実装（感度・反転の値を持つところまで）

## 完了条件

- [ ] キャラクターが画面のやや左に寄り、右肩越しに前方が見える
- [ ] マウス／右スティックでヨー・ピッチが回る
- [ ] ピッチが`+70度`・`-45度`で止まり、カメラが宙返りしない
- [ ] カメラ操作だけではキャラクターの向きが変わらない
- [ ] 移動入力でキャラクターがカメラ基準の移動方向へ向き直る
- [ ] 距離・オフセット・FOV・ピッチ制限・感度をInspectorから変更できる
- [ ] Consoleに新しいエラーが発生しない
- [ ] 関連仕様と矛盾していない

## 確認手順

1. Unityで確認用シーンを開きます。
2. Play Modeを開始します。
3. マウスを上下左右に動かし、カメラが回ることを確認します。
4. 上下に振り切り、見上げ・見下ろしが制限角度で止まることを確認します。
5. カメラだけを回し、キャラクターの向きが変わらないことを確認します。
6. `W`と`S`を順に入力し、キャラクターが進行方向へ向き直ることを確認します。
7. Inspectorで距離・オフセット・FOVを変更し、見え方へ反映されることを確認します。
8. Consoleに新しいエラーが出ていないことを確認します。

## 前提・依存タスク

- [カメラの基準配置](/spec/camera/CameraBasicPosition)の未決事項（基準距離・オフセット量）は仮値を置いて着手してかまいません。

## 実装時の注意点

- 数値をハードコードしないでください。すべて`[SerializeField]`またはScriptableObjectでInspector調整可能にします。
- 攻撃やエイムを理由にキャラクターをカメラ正面へ向き直らせないでください。攻撃はBGMと待機コードの照合による自動発動で、エイム操作は存在しません。
- 調整して決まった数値（基準距離・オフセット量など）は、仕様ページへ書き戻してください。
