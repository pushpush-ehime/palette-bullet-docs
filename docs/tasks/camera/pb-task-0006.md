# PB-TASK-0006｜カメラの障害物処理を実装する

## タスクの目的

壁や地形に遮られてキャラクターが見えなくなること、カメラが壁や地面を突き抜けて内部が見えることを防ぎます。狭い場所でも戦えるようにするための土台です。

## 完成時にできるようになること

- 壁とキャラクターの間にカメラが入りそうになると、自動的に手前へ寄って視界が保たれます。
- 狭い通路や壁際でも、カメラが壁を突き抜けて外の景色が見えることはありません。
- カメラが近づきすぎるときは、キャラクターが薄くなって消え、前方が見えたままになります。
- 障害物から離れると、カメラがなめらかに元の距離へ戻ります。
- 柱や手すりの前を走っても、カメラが激しく前後しません。

## 実施内容

- 注視点からカメラ位置へ球状の判定を飛ばし、毎フレーム目標距離を算出する
- 判定の太さを near clip と最大FOVから算出した値にする
- 判定の起点が障害物と重なっている場合のフォールバック（目標距離を最小距離まで縮める）を用意する
- 判定対象から、プレイヤー自身のコライダー・トリガーコライダー・小型の敵を除外する
- 寄る方向は上限速度つきの高速追従、戻る方向は遅くし、戻り開始にディレイ（ヒステリシス）を設ける
- 距離が縮むのに連動して、キャラクターを半透明化→非表示にし、オフセットX（右方向）を0へ縮める
- 一人称成分の比率でカメラ位置を補間する合成処理を入れる
- ゲーム状態のリセット時に、現在距離を目標距離へ即座に一致させる経路を用意する
- 上記のパラメータをInspectorから調整できるようにする

## 対象範囲

- カメラと地形の判定、距離の縮め・戻し
- 近づきすぎたときのキャラクター表示切り替えの制御
- 一人称状態との合成

## 対象外

- 半透明化の見た目そのもの（ディザ透過シェーダ・マテリアル）。デザイン班の担当
- ステージ側のコライダー・レイヤーの整備
- 大型敵のカメラ判定用コライダーの作成
- 基準距離・最小距離などの数値の確定（PB-TASK-0007）

## 完了条件

- [ ] 壁とキャラクターの間にカメラが入ると自動的に寄る
- [ ] 壁に体を密着させても、カメラが壁の外へ飛び出さない
- [ ] 柱や手すりの前を走ってもカメラが往復して暴れない
- [ ] 近づきすぎたときにキャラクターが半透明→非表示になり、前方が見える
- [ ] 寄ったときにオフセットXが縮み、キャラクターが画面の右半分を占領しない
- [ ] 壁際でドローモードやエイムを解除しても、復帰の途中で壁を貫通しない
- [ ] 敵やシャオンダマではカメラが寄らない
- [ ] 各パラメータをInspectorから変更できる
- [ ] Consoleに新しいエラーが発生しない
- [ ] 関連仕様と矛盾していない

## 確認手順

1. Unityで確認用シーンを開きます。
2. Play Modeを開始します。
3. 壁を背にして立ち、カメラが手前に寄って壁の裏が見えないことを確認します。
4. 壁に体を密着させ、カメラが壁の外へ飛び出さないことを確認します。
5. 柱の並ぶ場所を走り抜け、カメラが往復して暴れないことを確認します。
6. さらに狭い場所へ入り、キャラクターが薄くなって消え、前方が見えることを確認します。
7. 壁際でドローモードに入り、ダッシュでキャンセルして、復帰中に壁が貫通しないことを確認します。
8. 敵やシャオンダマの近くを通り、カメラが寄らないことを確認します。
9. Consoleに新しいエラーが出ていないことを確認します。

## 実装時の注意点

- **「一人称のときは処理を止める」という分岐を作らないでください。** 常に計算し、一人称成分の比率で合成します。分岐にすると、壁際で一人称から三人称へ戻る補間の途中で壁を貫通します。
- **判定の太さを通常時のFOVだけで決めないでください。** ダッシュやドローモードでFOVが広がると必要な太さが増えるため、最大FOV（現状はドローモードの水平100度）を基準に決めます。
- **判定の起点が壁の中にある場合のフォールバックを必ず入れてください。** 球状の判定は起点が障害物と重なっているとヒットを返さないことがあり、そのままだとカメラが壁の外へ飛び出します。
- カメラ位置は「起点＋方向×判定が進めた距離」で求めてください。衝突点と法線から逆算すると、壁の角でカメラが跳ねます。
- プレイヤー自身のコライダーとトリガーコライダーの除外を忘れないでください。どちらも入れたままだと常に距離が縮みます。
- カメラの更新は LateUpdate で、Player の移動更新より後に実行してください。
- 数値をハードコードしないでください。すべて `[SerializeField]` または ScriptableObject でInspector調整可能にします。
