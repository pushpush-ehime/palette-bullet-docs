# PB-TASK-0007｜カメラの基準値を決めて仕様へ反映する

## タスクの目的

カメラの数値はすべて基準距離に依存しており、それが決まらないと最小距離も判定の太さも決められません。実際に動かして調整し、確定値を仕様ページへ書き戻します。

## 完成時にできるようになること

- 基準距離とオフセット量が決まり、仕様ページに載っています。
- 下を向いてもカメラが地面に埋まらない配置になっています。
- 最小距離・判定の太さ・寄る/戻る速度が決まっています。
- 以降のタスクの担当者が、自分で仮値を決める必要がなくなります。

## 実施内容

- PB-TASK-0003 の実装上で、基準距離とオフセットX/Yを調整して決める
- 見下ろし限界（-45度）でカメラが地面に接触しない、ピッチ連動の基準距離カーブを決める
- 決まった基準距離をもとに最小距離を決める
- near clip 0.1 と最大FOV（水平100度）から判定の太さを算出し、余裕を加えた値を決める
- 柱の前を走る・壁際に寄るなどを繰り返しながら、寄る速度・戻る速度・戻り開始ディレイを決める
- キャラクターの半透明化を開始する距離と、完全に非表示になる距離を決める
- 決めた数値を仕様ページへ反映するPull Requestを出す

## 対象範囲

- カメラ関連の未決数値の決定
- 仕様ページへの反映

## 対象外

- 実装そのもの（PB-TASK-0003・0006）
- カメラ感度の目盛り（0〜100）を回転速度へ換算する式
- エイムの発動入力の決定
- ドローモード中・エイム中の感度倍率

## 完了条件

- [ ] 基準距離とオフセットX/Yが決まっている
- [ ] 見下ろし限界でカメラが地面に埋まらない
- [ ] 最小距離と判定の太さが決まっている
- [ ] 寄る速度・戻る速度・戻り開始ディレイが決まっている
- [ ] 半透明化の開始距離と非表示になる距離が決まっている
- [ ] 上記が仕様ページへ反映され、対象の🔴未決が消えている
- [ ] 関連仕様と矛盾していない

## 確認手順

1. Unityで確認用シーンを開き、Play Modeを開始します。
2. 平地を移動し、キャラクターの見え方と前方の視界のバランスから基準距離を決めます。
3. 右肩越しのオフセット量を、レティクル周辺が塞がらない範囲で決めます。
4. 下を向き、見下ろし限界でカメラが地面に埋まらないことを確認します。埋まる場合はピッチ連動カーブを調整します。
5. 壁を背にして立ち、最小距離と半透明化の距離を決めます。
6. 柱の並ぶ場所を走り、寄る速度・戻る速度・ディレイを決めます。
7. ドローモードとダッシュを一通り試し、決めた値で破綻がないことを確認します。
8. 決めた数値を仕様ページへ反映し、Pull Requestを作ります。

## 前提・依存タスク

- PB-TASK-0003（TPSカメラの基本動作）が完了していること。動くカメラがないと調整できません
- PB-TASK-0006（障害物処理）は、最小距離・判定の太さ・寄る/戻る速度を決める部分で必要になります

## 実装時の注意点

- **数値を決めたら必ず仕様ページへ書き戻してください。** Inspectorに入れただけで終わると、次の担当者がまた同じ調整をやり直すことになります。
- 決定の順序を守ってください。**基準距離 → 最小距離 → 判定の太さ** の順に依存しています。
- 判定の太さは最大FOV（ドローモードの水平100度）を基準に決めてください。通常時のFOVで決めると、ダッシュやドローモードの一瞬だけ壁が貫通します。
- キャラクターモデルが変わると、注視点の高さを含めて全パラメータの再調整が必要になります。モデル確定前の値は暫定として扱ってください。

## 提出・報告方法

1. 確認手順を実施します。
2. 仕様ページを更新するPull Requestを作ります。
3. NotionタスクへPull Requestと決定した数値を記載します。
