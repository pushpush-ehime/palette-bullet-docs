# PB-TASK-0020｜ラジクジラのキャラクターコンセプトデザイン

## タスクの目的

Playerの相棒として浮遊し、通常シャオンダマを背中側から出現させる「ラジクジラ」について、Gameplay上の役割と既存Playerイメージに合うキャラクターコンセプトを作成します。

本タスクでは3Dモデルや最終Animationを作らず、シルエット、色、サイズ感、背面構造、性格の方向性を比較し、後続制作が開始できる基準案を決定します。

## 完成時にできるようになること

- ラジクジラを画面内で一目で識別できる
- Playerとの並び、相対サイズ、浮遊時の見え方を判断できる
- シャオンダマが背中側から出現する構造をデザインへ反映できる
- 正面・側面・背面から3D化に必要な特徴を確認できる
- キャラクター設定とAnimation／VFX／Sound仕様を具体化できる

## 実施内容

### 1. 固定条件をデザインBriefへ整理する

- Playerの相棒である
- Playerから直接操作しない
- 自律的に浮遊し、Player周辺を追従する
- 敵のTargetにならず、HP／Damage／Deadを持たない
- 通常シャオンダマを背中側から出現させる
- 生成中も追従できる
- 戦闘画面とレティクルを過度に隠さない
- Player死亡演出中は非表示になる

### 2. シルエット案を作成する

少なくとも3案を、細部ではなくシルエットの差が分かる状態で作成します。各案には次を添えます。

- Playerとの相対サイズ
- 浮遊姿勢
- 正面・側面・背面の特徴
- 背中側のシャオンダマ出現領域
- 性格や印象を表す短いキーワード
- Gameplay画面での長所と懸念点

### 3. 色・素材・発光の方向性を比較する

既存Playerイメージと、色・音・透明感という作品コンセプトを参照し、採用候補へ2案以上のColor Variationを作ります。シャオンダマやWildcardと混同しないことも確認します。

### 4. 採用案を整理する

レビュー後、採用案または統合案について次をまとめます。

- 三面図またはそれに準じる形状資料
- 基本Color Palette
- PlayerとのScale比較
- 背面Spawn領域
- 表情または感情表現の方向性
- 浮遊・生成・非表示で必要になりそうな可動部
- 未決の世界観項目

## 対象範囲

- キャラクターデザインBrief
- シルエット3案以上
- Color Variation
- PlayerとのScale比較
- 採用候補の正面・側面・背面資料
- 3D／Animation／VFX／Sound担当への注記
- レビューと決定記録

## 対象外

- 最終3D Model、Rig、Texture
- Runtime追従処理
- シャオンダマ生成処理
- 最終Animation、VFX、SE、Voice
- 戦闘外で常時同行するかの最終決定
- 詳細な物語・台詞・会話システム

## 完了条件

- [ ] Gameplay上の固定条件がBriefへ記録されている
- [ ] シルエットの異なる案が3案以上ある
- [ ] 各案にPlayerとのScale比較がある
- [ ] 各案で背中側のSpawn領域を確認できる
- [ ] 戦闘画面を過度に隠さないか検討されている
- [ ] 採用候補にColor Variationが2案以上ある
- [ ] 採用案または次の修正方針がレビューで決定している
- [ ] 後続の3D・Animation・VFX・Sound担当が参照できる資料になっている
- [ ] 未決の世界観項目が推測で確定されず、判断事項として記録されている

## 確認手順

1. 既存Player画像の隣に各案を配置し、Scaleと作風の相性を比較します。
2. 1920×1080の仮Battle画面へ各案を縮小配置し、Player、レティクル、Enemyを隠さないことを確認します。
3. 背面図上で、複数シャオンダマを出現させる領域を説明できることを確認します。
4. 白黒表示でも各案のシルエットを識別できることを確認します。
5. デザイン、企画、実装担当でレビューし、採用または修正方針を記録します。

## 前提・依存タスク

なし。Player実装やPlayer Action／State Graph基盤の完成を待たずに開始できます。

## 実装時の注意点

- ラジクジラをPlayer装備やPlayer Stateの一部として設計しないでください。
- 背中側からのShaondama Spawnが読み取れない形状にしないでください。
- 具体的な追従速度や浮遊範囲をデザイン資料だけで確定しないでください。
- 最終品質のアセット制作へ進む前に、ゲーム画面上のScaleと視認性を確認してください。
- AI生成画像を探索に使用した場合は、使用範囲と人手で確定した要素を提出物へ明記してください。

## 提出・報告方法

1. 元データと確認用画像を共有ストレージへ配置します。
2. Notionタスクへ共有リンク、案の比較、レビュー結果を記載します。
3. 決定内容と未決事項を`キャラクター設定`仕様へ反映するための原稿を添付します。
